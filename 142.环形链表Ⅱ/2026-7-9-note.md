# 142. 环形链表 II

题目要求：给定一个链表的头节点 `head`，如果链表中存在环，返回环的入口节点；如果不存在环，返回 `None`。

这里的“环入口”指的是：链表从头节点出发，第一次进入环的那个节点。

例如：

```text
head
 |
 v
 3 -> 2 -> 0 -> -4
      ^         |
      |_________|
```

这个链表的环入口是节点 `2`。

---

## 方法一：哈希集合

代码思路：

```python
sets = set()
while head != None:
    if head in sets:
        return head
    if head not in sets:
        sets.add(head)
    head = head.next
return None
```

核心想法：

遍历链表时，把访问过的节点对象放进集合 `sets`。

如果某个节点之前已经出现过，说明链表从这个节点开始重复了，这个节点就是环的入口。

为什么第一次重复的节点就是环入口？

因为链表从头开始走，在进入环之前，每个节点只会经过一次。进入环之后，会沿着环一直走。当再次遇到某个已经访问过的节点时，这个节点一定是第一次进入环时的入口节点。

执行过程：

```text
每访问一个节点：
1. 先判断这个节点是否已经在 sets 中
2. 如果在，说明遇到了重复节点，直接返回它
3. 如果不在，就把它加入 sets
4. 继续访问下一个节点
```

复杂度：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

优点：

代码最直观，容易理解。

缺点：

需要额外的集合来保存访问过的节点，所以空间复杂度是 `O(n)`。

注意：

集合中保存的是节点对象本身，而不是节点的值 `val`。因为链表中可能有多个节点的值相同，但它们不是同一个节点。

---

## 方法二：修改节点值做标记

代码思路：

```python
while head is not None:
    if head.val is None:
        return head
    head.val = None
    head = head.next
return None
```

核心想法：

遍历链表时，把访问过的节点的 `val` 改成 `None`，相当于给节点做一个“已经访问过”的标记。

如果之后再次遇到 `val is None` 的节点，说明这个节点之前访问过，它就是环入口。

执行过程：

```text
每访问一个节点：
1. 如果 head.val is None，说明这个节点已经访问过，返回 head
2. 否则把 head.val 改成 None，表示已经访问过
3. 继续访问下一个节点
```

复杂度：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

优点：

不需要额外集合，空间复杂度降到了 `O(1)`。

缺点：

这个方法会修改原链表节点的值。

这通常不是推荐做法，因为题目一般默认不能破坏链表原本的数据。尤其是当节点原本的 `val` 就可能是 `None` 时，这个方法还会误判。

所以这个方法可以帮助理解“标记访问过的节点”这个思想，但正式解法更推荐哈希集合或快慢指针。

## 方法三：快慢指针

代码：

```python
slow = head
fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next

    if slow == fast:
        ptr = head
        while ptr != slow:
            ptr = ptr.next
            slow = slow.next
        return ptr

return None
```

这是本题最经典的解法。

它分为两步：

```text
第一步：用 fast 和 slow 判断链表是否有环
第二步：如果有环，再找到环的入口
```

---

### 1. 为什么快慢指针能判断有没有环？

一开始：

```python
slow = head
fast = head
```

然后每次循环：

```python
slow = slow.next
fast = fast.next.next
```

也就是：

```text
slow 每次走 1 步
fast 每次走 2 步
```

如果链表没有环：

`fast` 会一直往后走，最后走到 `None`，循环结束，返回 `None`。

对应代码：

```python
while fast and fast.next:
    ...
return None
```

这里必须判断 `fast and fast.next`，因为 `fast` 每次要走两步：

```python
fast = fast.next.next
```

如果 `fast` 或 `fast.next` 是 `None`，就不能继续走两步。

如果链表有环：

`fast` 和 `slow` 都会进入环。进入环之后，`fast` 每次比 `slow` 多走 1 步，所以 `fast` 会在环里不断追上 `slow`，最终两者一定会相遇。

可以把环想象成操场：

```text
slow 每次走 1 格
fast 每次走 2 格
fast 每轮都比 slow 多走 1 格
```

只要在同一个环里，快的那个一定会追上慢的那个。

---

### 2. 相遇点不一定是环入口

当代码执行到：

```python
if slow == fast:
```

只能说明链表中一定存在环。

但是这个相遇点不一定是环入口。

例如：

```text
head
 |
 v
A -> B -> C -> D -> E
     ^              |
     |______________|
```

环入口是 `B`，但是 `slow` 和 `fast` 可能在 `D` 或 `E` 相遇。

所以还需要第二步来找入口。

---

### 3. 为什么相遇后，一个指针回到 head，再一起走，就会在环入口相遇？

设：

```text
从 head 到环入口的距离 = a
环入口到第一次相遇点的距离 = x
环的长度 = b
```

图示：

```text
head ---- a ----> 环入口 ---- x ----> 相遇点
                  ^                  |
                  |                  |
                  |------ b ---------|
```

当 `slow` 和 `fast` 第一次相遇时：

```text
slow 走过的距离 = a + x
fast 走过的距离 = a + x + n * b
```

其中 `n * b` 表示 `fast` 比 `slow` 多绕了 `n` 圈环，`n` 是正整数。

因为 `fast` 的速度是 `slow` 的 2 倍，所以它走过的距离也是 `slow` 的 2 倍：

```text
2(a + x) = a + x + n * b
```

化简：

```text
a + x = n * b
```

再变形：

```text
a = n * b - x
```

这里是最关键的地方。

`x` 是从环入口走到相遇点的距离。

所以从相遇点继续往前走，要回到环入口，最短还需要：

```text
b - x
```

因为环总长是 `b`，已经从入口到相遇点走了 `x`，剩下 `b - x` 就能绕回入口。

而前面推出来：

```text
a = n * b - x
```

可以把它拆成：

```text
a = (n - 1) * b + (b - x)
```

这句话的意思是：

```text
从相遇点再走 a 步
= 先绕 (n - 1) 个完整的环
+ 最后再走 b - x 步
= 正好回到环入口
```

所以：

```text
从 head 出发走 a 步，会到环入口
从相遇点出发走 a 步，也会到环入口
```

因此代码里这样写：

```python
ptr = head
while ptr != slow:
    ptr = ptr.next
    slow = slow.next
return ptr
```

此时：

```text
ptr 从 head 出发
slow 从相遇点出发
两个指针每次都走 1 步
```

当 `ptr` 走了 `a` 步到达环入口时，`slow` 也刚好走了 `a` 步到达环入口。

所以它们再次相遇的位置就是环入口。

---

### 4. 用数字例子理解快慢指针推导

假设：

```text
a = 3
b = 5
x = 2
```

也就是：

```text
head 到环入口距离是 3
环长度是 5
环入口到相遇点距离是 2
```

那么：

```text
a + x = 3 + 2 = 5 = 1 * b
```

慢指针第一次相遇时走了 5 步，刚好等于一圈环长。

相遇点距离环入口还差：

```text
b - x = 5 - 2 = 3
```

而：

```text
a = 3
```

所以从相遇点继续走 `a` 步，也就是 3 步，正好回到环入口。

再看一个多绕圈的例子：

```text
a = 8
b = 5
x = 2
```

此时：

```text
a + x = 8 + 2 = 10 = 2 * b
```

从相遇点回入口最短还是：

```text
b - x = 3
```

但是 `a = 8`：

```text
8 = 5 + 3
```

也就是：

```text
先绕 1 个完整的环，再走 3 步回到入口
```

所以从相遇点走 `a` 步，仍然会到环入口。

---

### 5. 快慢指针代码逐行解释

```python
slow = head
fast = head
```

初始化快慢指针，都从头节点开始。

```python
while fast and fast.next:
```

只要 `fast` 还能继续往后走两步，就继续循环。

```python
slow = slow.next
fast = fast.next.next
```

慢指针走 1 步，快指针走 2 步。

```python
if slow == fast:
```

如果两个指针相遇，说明链表有环。

```python
ptr = head
```

新建一个指针 `ptr`，从头节点出发。

```python
while ptr != slow:
    ptr = ptr.next
    slow = slow.next
```

让 `ptr` 和 `slow` 每次都走 1 步。

`ptr` 从 `head` 出发，`slow` 从第一次相遇点出发。

它们最终会在环入口相遇。

```python
return ptr
```

返回环入口节点。

```python
return None
```

如果循环结束都没有相遇，说明链表没有环，返回 `None`。

---

## 三种方法对比

| 方法 | 是否修改链表 | 时间复杂度 | 空间复杂度 | 推荐程度 |
| --- | --- | --- | --- | --- |
| 哈希集合 | 否 | O(n) | O(n) | 容易理解 |
| 修改节点值标记 | 是 | O(n) | O(1) | 不推荐正式使用 |
| 快慢指针 | 否 | O(n) | O(1) | 最推荐 |

---

## 总结

哈希集合方法的核心是：

```text
见过的节点放进 set，再次遇到就是环入口。
```

修改节点值方法的核心是：

```text
把访问过的节点做标记，但会破坏原链表。
```

快慢指针方法的核心是：

```text
先用快慢指针判断是否有环；
第一次相遇后，让一个指针回到 head；
两个指针同步走，再次相遇的位置就是环入口。
```

快慢指针最关键的公式是：

```text
2(a + x) = a + x + n * b
```

化简后：

```text
a + x = n * b
a = n * b - x
a = (n - 1) * b + (b - x)
```

所以：

```text
从 head 走 a 步到入口；
从相遇点走 a 步也到入口。
```

这就是为什么 `ptr` 和 `slow` 同时一步一步走，最终会在环入口相遇。
