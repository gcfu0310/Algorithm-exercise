# 438. 找到字符串中所有字母异位词

## 题目核心

给定两个字符串 `s` 和 `p`，找出 `s` 中所有与 `p` 互为字母异位词的子串，并返回这些子串的起始下标。

字母异位词满足：

- 字符种类相同
- 每种字符出现的次数相同
- 字符排列顺序可以不同

例如，`"abc"`、`"bca"` 和 `"cab"` 互为字母异位词。

因为目标子串必须与 `p` 包含相同数量的字符，所以只需要检查 `s` 中所有长度为 `len(p)` 的子串。

设：

- `n = len(s)`
- `m = len(p)`
- 字符集大小为 `Σ`，本题只有 26 个小写英文字母

## 方法一：对子串排序后比较

### 思路

如果两个字符串互为字母异位词，那么它们排序后的结果一定相同。

先对 `p` 排序，然后依次截取 `s` 中每个长度为 `m` 的子串，对子串排序后与 `p` 比较：

```python
p = sorted(p)

for i in range(n - m + 1):
    sub = sorted(s[i:i + m])
    if sub == p:
        indexs.append(i)
```

例如：

```text
p = "abc"        排序后为 ['a', 'b', 'c']
子串 = "cba"     排序后为 ['a', 'b', 'c']
```

两者排序结果相同，因此该子串是 `p` 的字母异位词。

### 代码中的循环条件

```python
while i + m <= n:
```

它保证截取的区间 `[i, i + m)` 没有超出字符串范围。最后一个合法起点是 `n - m`。

### 复杂度

- 时间复杂度：`O((n - m + 1) × m log m)`，通常简写为 `O(nm log m)`
- 空间复杂度：`O(m)`，切片和排序结果需要额外空间

每个窗口都要重新截取和排序，没有利用相邻窗口之间只有两个字符发生变化这一特点。

### 优缺点

- 优点：思路直接，代码容易理解
- 缺点：重复排序，字符串较长时效率较低

## 方法二：字符计数数组 + 滑动窗口

### 思路

两个字符串互为字母异位词，等价于每种字符的出现次数完全相同。

本题只有小写英文字母，可以使用两个长度为 26 的数组：

- `s_count`：记录当前窗口内每个字符的数量
- `p_count`：记录 `p` 中每个字符的数量

字符通过下面的方式映射为 `0～25`：

```python
ord(char) - 97
```

因为 `ord('a') == 97`，所以：

```text
'a' → 0
'b' → 1
...
'z' → 25
```

也可以写成语义更清晰的形式：

```python
ord(char) - ord('a')
```

### 初始化窗口

先统计 `p` 和 `s` 的第一个长度为 `m` 的窗口：

```python
for i in range(m):
    s_count[ord(s[i]) - 97] += 1
    p_count[ord(p[i]) - 97] += 1
```

如果两个计数数组相同，起点 `0` 就是答案。

### 窗口如何移动

假设当前窗口为：

```text
s[i : i + m]
```

向右移动一格后：

- `s[i]` 离开窗口，数量减一
- `s[i + m]` 进入窗口，数量加一

```python
s_count[ord(s[i]) - 97] -= 1
s_count[ord(s[i + m]) - 97] += 1
```

然后比较：

```python
if s_count == p_count:
    indexs.append(i + 1)
```

这里记录的是新窗口的起点，所以是 `i + 1`。

### 复杂度

- 时间复杂度：`O(n × Σ)`；由于 `Σ = 26` 是常数，通常记为 `O(n)`
- 空间复杂度：`O(Σ)`；本题中为两个长度为 26 的数组，通常记为 `O(1)`

虽然移动窗口只更新两个位置，但每次执行 `s_count == p_count` 都要比较计数数组中的 26 个位置。

### 易错点

1. `len(s) < len(p)` 时应直接返回空列表，否则初始化窗口时可能访问越界。
2. 第一个窗口需要单独判断，后面的循环处理窗口移动后的结果。
3. 新窗口的起始下标是 `i + 1`，不是 `i`。
4. 该数组映射方式依赖题目字符均为小写英文字母。

## 方法三：使用 `diff` 优化滑动窗口

### 思路

方法二每移动一次窗口，都要比较两个长度为 26 的数组。方法三使用变量 `diff` 记录：

> 当前窗口与 `p` 的字符数量不相同的位置个数。

因此：

```text
diff == 0     所有字符数量都相同，是字母异位词
diff > 0      至少一种字符数量不同，不是字母异位词
```

例如：

```text
字符       a  b  c
s_count    1  2  0
p_count    1  1  1
是否不同   否 是 是
```

此时 `diff = 2`。

### 初始化 `diff`

统计第一个窗口后，遍历 26 个字符：

```python
for i in range(26):
    if s_count[i] != p_count[i]:
        diff += 1
```

### `update()` 的核心逻辑

窗口移动时只有离开的字符和进入的字符发生变化，因此不需要重新比较完整数组，只需要维护这两个字符对 `diff` 的影响。

```python
def update(idx, delta):
    nonlocal diff

    if s_count[idx] == p_count[idx]:
        diff += 1

    s_count[idx] += delta

    if s_count[idx] == p_count[idx]:
        diff -= 1
```

其中：

- `idx`：字符在计数数组中的下标
- `delta = -1`：字符离开窗口
- `delta = 1`：字符进入窗口

更新分为两步理解。

更新前：

- 如果原本相等，修改后将离开“相等状态”，所以 `diff += 1`
- 如果原本不相等，暂时不修改 `diff`

更新后：

- 如果现在相等，说明进入了“相等状态”，所以 `diff -= 1`
- 如果现在仍不相等，`diff` 不变

这套写法也能正确处理“原本不等，更新后仍然不等”的情况。

### 窗口移动

```python
update(ord(s[i]) - 97, -1)
update(ord(s[i + p_len]) - 97, 1)

if diff == 0:
    indexs.append(i + 1)
```

每次移动只更新两个字符，并通过 `diff == 0` 在常数时间内判断新窗口是否为字母异位词。

### 复杂度

- 时间复杂度：`O(n + Σ)`，本题中通常记为 `O(n)`
- 空间复杂度：`O(Σ)`，本题中通常记为 `O(1)`

与方法二相比，两者在固定的 26 字符集下都属于 `O(n)`，但方法三将每个窗口的 26 项数组比较优化为对整数 `diff` 的一次判断。

### 易错点

1. 必须在修改 `s_count[idx]` 之前判断它原来是否相等。
2. 修改后还要再次判断它现在是否相等。
3. 离开窗口使用 `-1`，进入窗口使用 `1`。
4. 即使离开和进入的是同一个字符，也可以连续调用两次 `update()`，最终状态仍然正确。

## 对嵌套函数的认识和理解

### 什么是嵌套函数

定义在另一个函数内部的函数叫作嵌套函数。

本题中的 `update()` 定义在 `findAnagrams()` 内部：

```python
def findAnagrams(self, s, p):
    def update(idx, delta):
        ...
```

因此，`update()` 是 `findAnagrams()` 的局部函数，只能在这次 `findAnagrams()` 调用内部直接使用。

### 本题为什么适合使用嵌套函数

`update()` 只是第三种解法中维护窗口状态的辅助操作，而且需要使用：

- `s_count`
- `p_count`
- `diff`

把它写成嵌套函数有以下好处：

1. 表明它只服务于 `findAnagrams()`，避免扩大函数的可见范围。
2. 可以直接访问外层函数的变量，不必把三个状态都写进参数列表。
3. 把重复的更新规则集中起来，减少两份相似代码带来的错误。

嵌套函数能够访问其定义位置外层作用域中的变量，这种保留外层变量引用的能力与闭包有关。

### 变量查找的 LEGB 规则

Python 查找变量时通常遵循 LEGB 顺序：

```text
Local      当前函数的局部作用域
Enclosing  外层函数的作用域
Global     当前模块的全局作用域
Built-in   Python 内置作用域
```

在 `update()` 中：

- `idx`、`delta` 是 Local 变量
- `diff`、`s_count`、`p_count` 来自 Enclosing 作用域

### 定义时尚未赋值是否有问题

代码先定义 `update()`，之后才给 `diff`、`s_count` 和 `p_count` 赋值：

```python
def update(idx, delta):
    ...

diff = 0
s_count = [0] * 26
p_count = [0] * 26
```

这种写法没有问题。函数体不是在定义 `update()` 时执行，而是在调用 `update()` 时执行。只要调用之前这些外层变量已经完成赋值，就能够正常访问。

## 对 `nonlocal` 的认识和理解

### `nonlocal` 的作用

`nonlocal` 用于嵌套函数中，声明某个变量来自最近一层已经绑定该变量的外层函数作用域，而不是当前函数的局部变量。

本题中：

```python
def update(idx, delta):
    nonlocal diff
    diff += 1
```

表示 `update()` 修改的是外层 `findAnagrams()` 中的 `diff`。

### 为什么 `diff` 必须声明为 `nonlocal`

下面的语句不是单纯读取：

```python
diff += 1
```

它近似等价于：

```python
diff = diff + 1
```

其中包含对变量名 `diff` 的重新赋值。只要函数体内对一个变量名赋值，Python 默认就会把它视为当前函数的局部变量。

如果删除 `nonlocal diff`：

```python
def update(idx, delta):
    if s_count[idx] == p_count[idx]:
        diff += 1
```

Python 会认为 `diff` 是 `update()` 的局部变量，但计算右侧表达式时，这个局部变量还没有初始值，因此会抛出：

```text
UnboundLocalError: local variable 'diff' referenced before assignment
```

### 为什么 `s_count` 和 `p_count` 不需要 `nonlocal`

`update()` 中有：

```python
s_count[idx] += delta
```

这里修改的是外层列表对象中的某个元素，并没有让变量名 `s_count` 指向一个新对象，因此不需要写：

```python
nonlocal s_count
```

可以把两者的区别理解为：

```python
# 修改对象内部内容，没有重新绑定变量名
s_count[idx] += delta

# 让变量名指向新的整数对象，发生了重新绑定
diff += 1
```

如果在嵌套函数中这样写：

```python
s_count = [0] * 26
```

这就是重新绑定 `s_count`。如果目标是修改外层的 `s_count` 变量，此时也需要声明 `nonlocal s_count`。

### `nonlocal` 与 `global` 的区别

- `nonlocal`：操作外层函数作用域中的变量
- `global`：操作模块全局作用域中的变量

本题的 `diff` 定义在 `findAnagrams()` 内部，不是模块全局变量，所以应使用 `nonlocal`，不能用 `global` 来表达同样的含义。

### 使用 `nonlocal` 时的注意点

1. 只能在嵌套函数中使用。
2. 外层函数中必须已经存在对应的变量绑定。
3. 它会让辅助函数修改外部状态，使用过多可能增加理解难度。
4. 如果状态很多，也可以考虑把状态作为参数传入并返回更新后的结果，或封装到类中。

## 三种方法对比

| 方法 | 判断依据 | 时间复杂度 | 空间复杂度 | 特点 |
| --- | --- | --- | --- | --- |
| 排序比较 | 排序后的字符序列相同 | `O(nm log m)` | `O(m)` | 最直观，但重复排序 |
| 计数数组滑动窗口 | 两个计数数组完全相同 | `O(n × Σ)`，固定字符集下为 `O(n)` | `O(Σ)` | 利用相邻窗口的变化 |
| `diff` 优化滑动窗口 | 不同计数位置的数量为 0 | `O(n + Σ)` | `O(Σ)` | 避免每轮完整比较数组 |

## 代码中的注意事项

当前文件在同一个 `Solution` 类中定义了三个同名的 `findAnagrams` 方法。

Python 类中后定义的同名方法会覆盖先定义的方法，因此实际执行：

```python
Solution().findAnagrams(s, p)
```

时只会调用第三种使用 `diff` 的滑动窗口方法，前两种方法不会被调用。

如果希望同时保留并分别测试三种方法，可以使用不同的方法名：

```python
def findAnagramsBySorting(self, s, p):
    ...

def findAnagramsByCounting(self, s, p):
    ...

def findAnagramsByDiff(self, s, p):
    ...
```

## 我的理解总结

第一种方法直接把“异位词”转化为“排序结果相同”，容易想到，但每个窗口都重新排序，浪费了相邻窗口之间的信息。

第二种方法使用固定长度滑动窗口。窗口每次只移出一个字符、移入一个字符，因此只更新对应计数，再用计数数组判断字符组成是否一致。

第三种方法继续优化判断过程。`diff` 把“两个数组是否完全相同”浓缩成“不同位置的数量是否为 0”，使每次窗口移动后的判断变成常数时间。

嵌套函数 `update()` 用来封装重复的状态更新规则。它可以读取外层的计数数组，并直接修改数组元素；而 `diff += 1` 会重新绑定变量名，所以必须通过 `nonlocal diff` 明确修改外层函数中的 `diff`。这正好体现了“修改可变对象的内容”和“重新绑定变量名”之间的区别。
