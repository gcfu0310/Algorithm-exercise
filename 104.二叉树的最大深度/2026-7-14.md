# 104. 二叉树的最大深度

这道题有两个常见解法，分别是递归法和层序遍历法。

## 1. 递归法

### 思路
- 递归地求出左子树和右子树的最大深度。
- 当前节点的深度等于左右子树较大深度再加 1。
- 当节点为空时，返回 0，作为递归终止条件。

### 代码核心
```python
if root is None:
    return 0
left_depth = self.maxDepth(root.left)
right_depth = self.maxDepth(root.right)
return max(left_depth, right_depth) + 1
```

### 优点
- 思路直接，代码简洁。
- 适合用递归解决树相关问题。

### 复杂度
- 时间复杂度：$O(n)$
- 空间复杂度：$O(h)$，其中 $h$ 是树高

## 2. 层序遍历法（广度优先搜索）

### 思路
- 使用队列保存当前层的节点。
- 每一轮遍历一层，深度加 1。
- 将当前层节点的左右孩子加入下一层队列。
- 直到队列为空，返回深度。

### 代码核心
```python
queue = [root]
depth = 0
while queue:
    depth += 1
    next_level = []
    for node in queue:
        if node.left is not None:
            next_level.append(node.left)
        if node.right is not None:
            next_level.append(node.right)
    queue = next_level
return depth
```

### 优点
- 直观地按层计算深度。
- 适合理解“层”的概念。

### 复杂度
- 时间复杂度：$O(n)$
- 空间复杂度：$O(w)$，其中 $w$ 是最大层宽度

## 3. 小结
- 递归法更简洁，适合熟悉树递归的场景。
- 层序遍历法更容易从“层级”角度理解问题。
- 两种方法的时间复杂度都是 $O(n)$。
