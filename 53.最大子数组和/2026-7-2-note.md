## 53.最大子数组和

### 方法：动态规划
- 一句话理解：我加上你变大，就保留你；否则就保留我自己
- 假设数组为nums[n],第i个数的结尾的最大子数组和为f(i),那么这个f(i) = max(f(i-1)+nums[i],nums[i])
- 可以用pre来记录前缀和以及一个变量来记录pre中的最大值即可，不用Hashmap从而降低空间复杂度

### Codex补充与评价
- 你的核心理解是正确的：这道题的关键就是判断“前面的连续子数组要不要接到当前数字上”。如果 `f(i-1) + nums[i]` 比 `nums[i]` 大，说明前面的贡献是正向的，可以接上；否则就从 `nums[i]` 重新开始。
- 更准确地说，`pre` 记录的不是传统意义上的“前缀和”，而是“以当前元素结尾的最大连续子数组和”。普通前缀和通常表示 `nums[0] + ... + nums[i]`，但这里的 `pre` 会在前面拖累当前结果时重新开始。
- `sum_max` 用来记录所有 `pre` 中出现过的最大值，也就是全局最大子数组和。因为最大子数组不一定以最后一个元素结尾，所以只维护 `pre` 还不够，必须同步维护一个全局答案。
- 状态转移可以写成：

```python
pre = max(pre + num, num)
sum_max = max(sum_max, pre)
```

- 你的代码逻辑是对的，也能处理全负数数组。例如 `[-3, -2, -5]`，答案应该是 `-2`，因为子数组至少要包含一个元素，不能返回 `0`。
- 时间复杂度是 `O(n)`，只遍历一次数组；空间复杂度是 `O(1)`，因为只用了 `pre` 和 `sum_max` 两个变量。

### 一个更精炼的写法

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        pre = nums[0]
        sum_max = nums[0]

        for num in nums[1:]:
            pre = max(pre + num, num)
            sum_max = max(sum_max, pre)

        return sum_max
```

这版和你的思路完全一致，只是把 `if` 判断压缩成了 `max` 表达式。
