# 11. 盛最多水的容器

## 今日总结

这题还是非常经典的双指针题，但第一次没有想出来，最后看题解才理解核心：每次移动较短的那一边。

这道题最重要的点不是“会写双指针”，而是要想明白：为什么可以放心丢掉较短的那根柱子。

## 核心思路：双指针

容器的面积由两部分决定：

```text
面积 = 两根柱子之间的距离 * 两根柱子中较短的高度
```

也就是：

```python
area = (j - i) * min(height[i], height[j])
```

用两个指针分别指向数组两端：

- `i`：左边界。
- `j`：右边界。
- `w_max`：当前找到的最大面积。

每次计算当前左右边界能形成的面积，然后移动高度较小的那个指针。

## 为什么移动短板

假设当前：

```text
height[i] <= height[j]
```

当前面积是：

```text
(j - i) * height[i]
```

如果保持左指针 `i` 不动，只移动右指针 `j`：

- 宽度一定会变小。
- 高度最多也只能由 `height[i]` 决定，因为左边是短板。

所以在左指针不变的情况下，不管右指针怎么移动，面积都不可能超过当前这个面积。

因此，`height[i]` 这个位置已经没有继续保留的价值，可以放心把左指针右移。

同理，如果：

```text
height[i] > height[j]
```

右边是短板，就移动右指针。

## 算法步骤

1. 左指针 `i` 指向开头，右指针 `j` 指向结尾。
2. 计算当前面积 `(j - i) * min(height[i], height[j])`。
3. 用当前面积更新最大值 `w_max`。
4. 移动高度较小的那个指针。
5. 当两个指针相遇时结束。

## 代码对应理解

```python
if height[i] < height[j]:
    w = (j - i) * height[i]
    i += 1
else:
    w = (j - i) * height[j]
    j -= 1
```

这里先用较短的高度计算面积，然后移动较短的一边。

因为面积受短板限制，移动高的一边没有意义：宽度变小了，短板还没变，面积不可能变大。

## 复杂度

- 时间复杂度：`O(n)`，左右指针总共最多移动 `n - 1` 次。
- 空间复杂度：`O(1)`，只使用了几个变量。
