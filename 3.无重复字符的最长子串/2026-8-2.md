# 3. 无重复字符的最长子串

## 一、认识题目

题目要求：

> 给定一个字符串 `s`，找出其中不包含重复字符的最长子串，并返回它的长度。

例如：

```text
s = "abcabcbb"
```

其中无重复字符的最长子串可以是：

```text
"abc"
```

所以答案是：

```text
3
```

### 首先理解“子串”

子串必须是原字符串中连续的一段。

例如，对于：

```text
"abcde"
```

下面是子串：

```text
"abc"
"bcd"
"de"
```

下面不是子串：

```text
"ace"
```

因为字符在原字符串中并不连续。

如果题目说的是“子序列”，才允许跳过某些字符。因此，看到“子串”时，首先应该想到：

> 我们需要研究字符串中的连续区间。

### 题目中的限制条件

这个连续区间还必须满足：

```text
区间内不能出现重复字符
```

因此可以把题目转化为：

> 在字符串中寻找一个最长的连续区间，使区间中的所有字符都不重复。

## 二、先从暴力方法开始思考

最直接的想法是枚举所有子串，然后判断其中是否有重复字符。

对于每一个起点 `left`，尝试不同的终点 `right`：

```text
s[left:right + 1]
```

例如：

```text
s = "abc"
```

可以枚举：

```text
"a"、"ab"、"abc"
"b"、"bc"
"c"
```

再逐个判断字符是否重复。

这种方法虽然容易想到，但会反复检查很多相同的字符。如果枚举所有子串并逐个检查，时间复杂度可能达到 `O(n³)`；即使在枚举过程中使用集合优化检查，通常也需要 `O(n²)`。

接下来要思考：

> 能不能在扫描字符串时，保留上一次检查得到的信息，而不是每次重新开始？

## 三、从暴力方法引出滑动窗口

假设当前已经找到一个没有重复字符的区间：

```text
left              right
  ↓                  ↓
  a   b   c
```

现在让 `right` 向右移动，并加入新字符 `d`：

```text
a b c d
```

如果 `d` 没有出现在当前区间中，那么新区间仍然满足条件，可以继续扩大。

如果新字符在当前区间中已经存在，例如：

```text
a b c a
```

此时区间不再满足“无重复字符”。但没有必要完全重新检查字符串，只需要让左边界 `left` 向右移动，并逐步移除左侧字符，直到重复被消除。

这就形成了滑动窗口：

```text
窗口 = s[left:right + 1]
```

- `right` 负责尝试加入新字符、扩大窗口；
- `left` 负责在条件不满足时移除旧字符、缩小窗口。

## 四、为什么这道题适合滑动窗口？

可以从题目中识别三个特征：

### 1. 研究的是连续区间

题目要求的是子串，而不是子序列。

### 2. 区间需要满足某个条件

当前条件是：

```text
窗口中的字符不能重复
```

### 3. 右边加入字符后，可以通过移动左边界恢复条件

如果加入新字符后出现重复，只要从左边逐个删除字符，就能重新得到无重复窗口。

因此，可以使用可变长度滑动窗口。

以后看到类似描述时，也可以考虑这种方法：

```text
最长/最短 + 连续子数组或子串 + 某个窗口限制
```

## 五、代码实现

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        left = 0
        substring = set()
        n = len(s)
        max_length = 0

        for right in range(n):
            while s[right] in substring:
                substring.remove(s[left])
                left += 1

            substring.add(s[right])
            max_length = max(right - left + 1, max_length)

        return max_length
```

## 六、变量分别表示什么？

### `left`

```python
left = 0
```

表示当前滑动窗口的左边界。

### `right`

```python
for right in range(n):
```

表示当前准备加入窗口的字符下标，也是处理完成后窗口的右边界。

`right` 从左到右扫描整个字符串，并且不会向左退回。

### `substring`

```python
substring = set()
```

它是一个集合，保存当前窗口内的所有字符。

虽然变量名叫 `substring`，但它实际保存的不是字符串，而是字符集合。为了让语义更清楚，也可以命名为：

```python
window_chars = set()
```

集合适合这道题，因为它可以平均在 `O(1)` 时间内完成：

```python
char in window_chars
window_chars.add(char)
window_chars.remove(char)
```

### `max_length`

```python
max_length = 0
```

记录到目前为止遇到的最长合法窗口长度。

## 七、滑动窗口的不变量

理解这段代码最重要的是明确它一直维护什么条件：

> 每轮循环处理结束后，`s[left:right + 1]` 中没有重复字符，并且 `substring` 恰好保存这个窗口中的所有字符。

代码中的每一步都在维护这个不变量：

1. `right` 尝试加入一个新字符；
2. 如果该字符会造成重复，就移动 `left` 并删除左侧字符；
3. 重复消失后，将新字符加入集合；
4. 此时窗口重新合法，计算窗口长度。

## 八、逐行理解核心循环

### 1. 右指针向右扫描

```python
for right in range(n):
```

每轮循环尝试把 `s[right]` 加入当前窗口。

### 2. 出现重复时收缩窗口

```python
while s[right] in substring:
    substring.remove(s[left])
    left += 1
```

只要新字符 `s[right]` 已经存在于当前窗口，就说明还不能加入它。

此时不断：

1. 从集合中删除窗口最左侧字符；
2. 将左边界向右移动。

直到集合中不再包含 `s[right]`。

### 3. 将新字符加入窗口

```python
substring.add(s[right])
```

执行到这里时，重复已经被消除，所以可以安全地将当前字符加入集合。

### 4. 更新最大长度

```python
max_length = max(right - left + 1, max_length)
```

此时窗口合法，因此可以用它更新答案。

## 九、为什么窗口长度是 `right - left + 1`？

假设：

```text
left = 2
right = 4
```

窗口包含的下标是：

```text
2、3、4
```

一共有三个位置：

```text
4 - 2 + 1 = 3
```

因为左右边界都包含在窗口中，所以需要加 `1`。

## 十、为什么必须使用 `while`，不能只使用 `if`？

考虑：

```text
s = "abba"
```

当 `right` 指向第二个 `b` 时，当前窗口为：

```text
"ab"
```

集合为：

```python
{'a', 'b'}
```

新字符 `b` 已经存在。

第一次移动 `left`，删除 `a`：

```text
窗口准备变为："b"
集合：{'b'}
```

但集合中仍然有 `b`，重复问题还没有解决，所以还需要继续删除一次。

第二次删除旧的 `b` 后，新字符 `b` 才可以加入。

因此必须写成：

```python
while s[right] in substring:
```

意思是：

> 只要重复仍然存在，就继续缩小窗口。

如果只写 `if`，可能只删除一个字符后就停止，窗口仍然存在重复。

## 十一、示例一：`abcabcbb`

初始状态：

```text
left = 0
substring = {}
max_length = 0
```

| `right` | 当前字符 | 处理后的窗口 | 集合 | 最大长度 |
| ---: | --- | --- | --- | ---: |
| 0 | `a` | `a` | `{a}` | 1 |
| 1 | `b` | `ab` | `{a,b}` | 2 |
| 2 | `c` | `abc` | `{a,b,c}` | 3 |
| 3 | `a` | `bca` | `{a,b,c}` | 3 |
| 4 | `b` | `cab` | `{a,b,c}` | 3 |
| 5 | `c` | `abc` | `{a,b,c}` | 3 |
| 6 | `b` | `cb` | `{b,c}` | 3 |
| 7 | `b` | `b` | `{b}` | 3 |

最终返回：

```text
3
```

## 十二、示例二：详细理解 `abba`

### 处理下标 0 的 `a`

```text
窗口：a
left = 0
right = 0
max_length = 1
```

### 处理下标 1 的 `b`

```text
窗口：ab
left = 0
right = 1
max_length = 2
```

### 处理下标 2 的 `b`

新字符 `b` 与窗口中的 `b` 重复。

先删除左侧的 `a`：

```text
集合中仍然存在 b
```

再删除左侧的旧 `b`：

```text
重复消失
left = 2
```

加入新的 `b`：

```text
窗口：b
```

### 处理下标 3 的 `a`

`a` 不在当前窗口中，可以直接加入：

```text
窗口：ba
长度：2
```

最终答案为 `2`。

## 十三、为什么时间复杂度是 `O(n)`？

代码中有一个 `for` 循环和一个 `while` 循环，看起来像是 `O(n²)`，但实际上不是。

原因是：

- `right` 从左到右移动，每个位置只访问一次；
- `left` 也只会从左到右移动，不会后退；
- 每个字符最多被加入集合一次、移出集合一次。

所以两个指针总共移动的次数不超过约 `2n`：

```text
O(n + n) = O(n)
```

因此：

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(min(n, 字符集大小))`。

如果题目字符范围有限，例如只包含 ASCII 字符，那么集合大小也存在固定上限。

## 十四、边界情况

### 空字符串

```text
s = ""
```

循环不会执行，返回初始值：

```text
0
```

### 只有一个字符

```text
s = "a"
```

最长无重复子串就是它本身，返回 `1`。

### 所有字符相同

```text
s = "bbbbb"
```

每次加入新的 `b` 前，都要移除旧的 `b`，窗口最大长度为 `1`。

### 所有字符都不同

```text
s = "abcdef"
```

窗口一直扩大，从不收缩，最终返回整个字符串长度 `6`。

## 十五、如何从题目想到这种方法？

可以使用下面的思考流程。

### 第一步：题目求什么范围？

题目求的是子串，所以研究对象是一个连续区间：

```text
s[left:right + 1]
```

### 第二步：这个区间需要满足什么条件？

区间内不能存在重复字符。

### 第三步：如何快速判断条件？

使用集合保存窗口中的字符：

```python
substring = set()
```

这样可以快速判断新字符是否重复。

### 第四步：条件满足时做什么？

扩大右边界，并尝试更新最长长度。

### 第五步：条件不满足时做什么？

移动左边界，移除窗口左侧字符，直到窗口重新合法。

### 第六步：答案应该在什么时候更新？

消除重复并加入当前字符之后，窗口才是合法窗口，此时更新答案：

```python
max_length = max(max_length, right - left + 1)
```

整个推导可以概括为：

```text
最长子串
→ 连续区间
→ 使用左右边界表示区间
→ 区间需要满足无重复条件
→ 使用集合记录区间字符
→ 右指针扩大窗口
→ 重复时左指针缩小窗口
→ 得到滑动窗口解法
```

## 十六、可变长度滑动窗口模板

这道题对应的通用结构是：

```python
left = 0
window = set()
answer = 0

for right in range(len(data)):
    # 当加入 data[right] 会破坏窗口条件时
    while 窗口不满足条件:
        移除 data[left] 对窗口状态的影响
        left += 1

    将 data[right] 加入窗口状态
    answer = max(answer, right - left + 1)

return answer
```

模板不能直接死记，真正需要确定的是：

1. 窗口表示什么；
2. 用什么数据结构记录窗口状态；
3. 什么情况下需要移动左指针；
4. 左指针移动时需要删除什么信息；
5. 在什么时机更新答案。

## 十七、常见易错点

### 1. 把子串理解成子序列

子串必须连续，不能跳着选择字符。

### 2. 重复时只移动一次左指针

重复字符可能不在窗口最左端，所以需要使用 `while` 持续收缩窗口。

### 3. 移动 `left` 却不更新集合

错误示例：

```python
left += 1
```

如果不同时执行：

```python
substring.remove(s[left])
```

集合就不能真实反映窗口内容。

### 4. 忘记在长度公式中加一

窗口左右边界都包含在内：

```python
right - left + 1
```

### 5. 在窗口仍不合法时更新答案

应该先通过 `while` 消除重复，再加入当前字符，最后计算长度。

## 十八、总结

这道题的关键不是单独记住一段滑动窗口代码，而是建立下面的推导：

> 题目要求最长子串，所以研究连续区间；区间要求字符不重复，所以用集合记录字符；右指针负责扩展区间，出现重复时左指针负责缩小区间，窗口恢复合法后更新最大长度。

代码中的核心不变量是：

> 每轮处理完成后，`s[left:right + 1]` 是一个没有重复字符的窗口，集合中的字符与窗口内容完全一致。

只要理解并维护这个不变量，就不需要死记代码。
