# 169. 多数元素

## 今日总结

这题是对哈希表的再一次复习。题解有很多方法，比如排序、哈希表、摩尔投票法。综合下来，哈希表方法目前最直观、最好理解，也比较稳。

## 题目关键

多数元素指的是在数组中出现次数大于 `n / 2` 的元素。

题目保证多数元素一定存在，所以只要某个元素的计数超过 `len(nums) / 2`，就可以直接返回。

## 核心思路：哈希表计数

用字典 `dic` 记录每个数字出现的次数：

- 如果 `num` 第一次出现，就把它加入字典，次数记为 `1`。
- 如果 `num` 已经出现过，就让它的次数加 `1`。
- 每次更新后，判断它的次数是否已经超过数组长度的一半。

对应关系：

```python
dic[num] = 出现次数
```

## 为什么可以提前返回

因为多数元素的定义是：

```text
出现次数 > n / 2
```

一旦某个数字的次数超过一半，它就一定是多数元素，不可能再有另一个数字也超过一半。

所以代码里可以在循环过程中直接判断：

```python
if dic[num] > len(nums) / 2:
    return num
```

## 方法对比

- 哈希表：思路最直观，统计每个元素出现次数。
- 排序：排序后，中间位置的元素一定是多数元素，但时间复杂度更高。
- 摩尔投票法：空间复杂度最优，但理解起来更绕一些。

## 复杂度

- 时间复杂度：`O(n)`，每个元素最多遍历一次。
- 空间复杂度：`O(n)`，最坏情况下字典中会存下多个不同元素。
