# 两数之和学习笔记（2026-6-23）

## 1. 今日收获

- 暴力枚举可以解决问题，但时间复杂度较高。
- 双层 `for` 循环比 `for + while` 的写法更简洁，结构也更清楚。
- 哈希表可以用空间换时间，把两数之和从 `O(n^2)` 优化到 `O(n)`。
- 做算法题时，要同时关注时间复杂度和空间复杂度。
- 后续需要系统补充数据结构，尤其是哈希表、数组、集合等基础内容。

## 2. 解法一：暴力枚举

### 2.1 思路

暴力解法的核心思路是：枚举数组中的每一对数字，判断它们的和是否等于 `target`。

可以把代码结构写成：

```python
for i in range(n):
    for j in range(i + 1, n):
        if nums[i] + nums[j] == target:
            return [i, j]
```

这里让 `j` 从 `i + 1` 开始，可以避免重复比较，也避免同一个元素被使用两次。

### 2.2 时间复杂度

暴力解法是两层循环，但不是完整的 `n * n` 次比较。

假设 `n = 4`，比较次数是：

```text
i = 0: j = 1, 2, 3   比较 3 次
i = 1: j = 2, 3      比较 2 次
i = 2: j = 3         比较 1 次
i = 3: 没有          比较 0 次
```

总比较次数是：

```text
3 + 2 + 1 = 6
```

如果 `n = 5`，比较次数是：

```text
4 + 3 + 2 + 1 = 10
```

一般来说，总比较次数为：

```text
(n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2
```

展开后是：

```text
(n^2 - n) / 2
```

在复杂度分析里，只关注增长最快的项，并忽略常数，所以：

```text
(n^2 - n) / 2  =>  O(n^2)
```

因此，暴力解法的时间复杂度是：

```text
O(n^2)
```

含义是：数组长度变大时，运行时间大致按平方级增长。

### 2.3 空间复杂度

空间复杂度关注的是：算法额外使用了多少内存。

暴力解法中，除了 `n`、`i`、`j` 这些变量之外，没有额外创建数组、字典或集合。

这些变量占用的空间不会随着 `n` 的增长而增长，所以空间复杂度是：

```text
O(1)
```

也叫常数空间复杂度。

## 3. 解法二：哈希表

### 3.1 思路

哈希表解法的核心思路是：一边遍历数组，一边记录已经见过的数字和它们的下标。

遍历到当前数字 `num` 时，需要寻找的另一个数字是：

```python
need = target - num
```

如果 `need` 已经在哈希表里，说明答案找到了：

```python
if need in hashmap:
    return [hashmap[need], i]
```

如果没找到，就把当前数字和下标存入哈希表：

```python
hashmap[num] = i
```

完整核心结构可以写成：

```python
hashmap = {}

for i, num in enumerate(nums):
    need = target - num
    if need in hashmap:
        return [hashmap[need], i]
    hashmap[num] = i
```

### 3.2 时间复杂度

核心循环是：

```python
for i, num in enumerate(nums):
```

这个循环最多执行 `n` 次。

每一轮循环主要做三件事：

```python
need = target - num
```

计算差值是常数时间，记作 `O(1)`。

```python
if need in hashmap:
```

字典查找在平均情况下是 `O(1)`。

```python
hashmap[num] = i
```

字典插入在平均情况下也是 `O(1)`。

所以每一轮循环是 `O(1)`，总共有 `n` 轮，因此总时间复杂度是：

```text
O(n)
```

含义是：数组长度变大时，运行时间大致线性增长。

### 3.3 空间复杂度

哈希表解法额外使用了一个字典：

```python
hashmap = {}
```

在最坏情况下，如果一直没有提前找到答案，字典里可能存下数组中几乎所有元素，也就是 `n` 个元素。

因此，额外空间会随着 `n` 增长，空间复杂度是：

```text
O(n)
```

## 4. 两种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
| --- | --- | --- | --- |
| 暴力枚举 | `O(n^2)` | `O(1)` | 不需要额外数据结构，但速度较慢 |
| 哈希表 | `O(n)` | `O(n)` | 使用字典存储已遍历元素，用空间换时间 |

## 5. 总结

这道题最重要的收获是：哈希表可以快速判断某个数字是否已经出现过。

暴力枚举是“直接检查所有可能组合”，哈希表是“记录已经见过的数字，遇到当前数字时反查需要的另一个数字”。两种方法都能解决问题，但哈希表的效率更高。
