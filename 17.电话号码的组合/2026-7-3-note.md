## 17. 电话号码的字母组合

### 题目核心

给定一个只包含数字 `2-9` 的字符串 `digits`，返回这些数字可以表示的所有字母组合。

例如：

```python
digits = "23"
```

数字和字母的对应关系是：

```python
2 -> ["a", "b", "c"]
3 -> ["d", "e", "f"]
```

所以结果是：

```python
["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]
```

---

## 方法一：递归回溯

代码：

```python
class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        dicts = {
            '2':["a","b","c"],
            '3':["d","e","f"],
            '4':["g","h","i"],
            '5':["j","k","l"],
            '6':["m","n","o"],
            '7':["p","q","r","s"],
            '8':["t","u","v"],
            '9':["w","x","y","z"]
        }
        combinations = []
        combination = []

        def back(index:int):
            if index == len(digits):
                combinations.append(''.join(combination))
            else:
                digit = digits[index]
                for letter in dicts[digit]:
                    combination.append(letter)
                    back(index+1)
                    combination.pop()

        back(0)
        return combinations
```

### 如何理解递归回溯

可以把回溯理解成：

> 一位一位地选字母，选完一个完整组合后，退回上一步，换另一个字母继续试。

这里有两个重要变量：

```python
combination = []
combinations = []
```

它们的含义分别是：

```python
combination
```

表示当前正在构造的一个组合。

比如正在构造 `"ad"` 时，`combination` 是：

```python
["a", "d"]
```

而：

```python
combinations
```

表示最终答案列表，用来保存所有完整组合。

### `index` 是什么意思

递归函数是：

```python
def back(index:int):
```

这里的 `index` 表示：现在正在处理 `digits` 的第几位数字。

比如：

```python
digits = "23"
```

那么：

```python
index = 0
```

表示正在处理数字 `"2"`。

```python
index = 1
```

表示正在处理数字 `"3"`。

```python
index = 2
```

表示两个数字都处理完了，此时可以把当前组合加入答案。

### 递归终止条件

```python
if index == len(digits):
    combinations.append(''.join(combination))
```

当 `index == len(digits)` 时，说明每一位数字都已经选过一个字母了。

比如：

```python
digits = "23"
combination = ["a", "d"]
```

此时 `index == 2`，说明已经选出了一个完整组合，所以执行：

```python
combinations.append(''.join(combination))
```

把：

```python
["a", "d"]
```

转换成：

```python
"ad"
```

然后加入结果列表。

### 回溯的关键三步

这三行是回溯的核心：

```python
combination.append(letter)
back(index+1)
combination.pop()
```

可以理解成：

```python
combination.append(letter)
```

先选择当前字母。

```python
back(index+1)
```

然后进入下一位数字，继续选择下一个字母。

```python
combination.pop()
```

等下一层递归全部处理完后，撤销刚才的选择，换当前数字的下一个字母。

这就是“回溯”两个字的含义：先往前走，走完后退回来，换另一条路。

---

## 用 `digits = "23"` 跟踪回溯过程

初始状态：

```python
digits = "23"
combination = []
combinations = []
```

执行：

```python
back(0)
```

### 第 1 层：处理数字 `"2"`

因为：

```python
index = 0
digits[index] = "2"
dicts["2"] = ["a", "b", "c"]
```

所以这一层会依次尝试：

```python
"a", "b", "c"
```

先选择 `"a"`：

```python
combination.append("a")
```

此时：

```python
combination = ["a"]
```

然后进入下一层：

```python
back(1)
```

### 第 2 层：处理数字 `"3"`

因为：

```python
index = 1
digits[index] = "3"
dicts["3"] = ["d", "e", "f"]
```

所以这一层会依次尝试：

```python
"d", "e", "f"
```

先选择 `"d"`：

```python
combination.append("d")
```

此时：

```python
combination = ["a", "d"]
```

然后进入下一层：

```python
back(2)
```

### 第 3 层：到达终止条件

因为：

```python
index = 2
len(digits) = 2
```

所以：

```python
index == len(digits)
```

说明当前组合已经完整，于是加入答案：

```python
combinations.append("ad")
```

此时：

```python
combinations = ["ad"]
```

然后这一层递归结束，回到上一层，也就是处理 `"3"` 的那一层。

### 回退一步，换下一个字母

回到处理 `"3"` 的那一层后，会执行：

```python
combination.pop()
```

把刚才选的 `"d"` 撤销。

此时：

```python
combination = ["a"]
```

然后继续尝试 `"3"` 对应的下一个字母 `"e"`。

```python
combination.append("e")
back(2)
combination.pop()
```

得到：

```python
"ae"
```

再尝试 `"f"`，得到：

```python
"af"
```

当 `"d"`, `"e"`, `"f"` 都尝试完后，说明以 `"a"` 开头的组合全部找完了：

```python
"ad", "ae", "af"
```

这时会回到处理 `"2"` 的那一层。

### 再回退，换 `"2"` 的下一个字母

之前第一层选的是 `"a"`，现在 `"a"` 开头的所有情况都完成了，所以执行：

```python
combination.pop()
```

撤销 `"a"`。

此时：

```python
combination = []
```

接着第一层继续选择 `"2"` 对应的下一个字母 `"b"`。

然后重复同样流程：

```python
["b"] -> ["b", "d"] -> "bd"
["b"] -> ["b", "e"] -> "be"
["b"] -> ["b", "f"] -> "bf"
```

再选择 `"c"`：

```python
["c"] -> ["c", "d"] -> "cd"
["c"] -> ["c", "e"] -> "ce"
["c"] -> ["c", "f"] -> "cf"
```

最终结果：

```python
["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]
```

### 回溯树

可以把整个过程想成一棵树：

```text
                 []
          /       |       \
        a         b        c
      / | \     / | \    / | \
    d   e  f   d  e  f  d  e  f
   ad  ae af  bd be bf cd ce cf
```

每一层处理一个数字：

```text
第 0 层：还没有选任何字母
第 1 层：处理 digits[0]，也就是数字 "2"
第 2 层：处理 digits[1]，也就是数字 "3"
第 3 层：所有数字处理完，收集答案
```

### 为什么需要 `pop`

如果没有：

```python
combination.pop()
```

那么上一次选择的字母不会被撤销，后面的组合就会乱掉。

比如构造完 `"ad"` 后：

```python
combination = ["a", "d"]
```

如果不 `pop()` 掉 `"d"`，接下来选择 `"e"` 时会变成：

```python
["a", "d", "e"]
```

这就不对了，因为 `"23"` 只需要两个字母的组合。

所以 `pop()` 的作用是：

> 当前分支走完后，撤销当前选择，回到进入这个分支之前的状态。

## 方法二：迭代扩展

代码：

```python
class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        d = {
            "2": ["a", "b", "c"],
            "3": ["d", "e", "f"],
            "4": ["g", "h", "i"],
            "5": ["j", "k", "l"],
            "6": ["m", "n", "o"],
            "7": ["p", "q", "r", "s"],
            "8": ["t", "u", "v"],
            "9": ["w", "x", "y", "z"],
        }
        ans = d[digits[0]]
        if len(digits) == 1:
            return ans
        for n in digits[1:]:
            ans = [a + b for a in ans for b in d[n]]
        return ans
```

### 这句代码的运行逻辑

核心代码是：

```python
ans = [a + b for a in ans for b in d[n]]
```

它等价于：

```python
new_ans = []

for a in ans:
    for b in d[n]:
        new_ans.append(a + b)

ans = new_ans
```

含义是：

> 把已有组合 `ans` 中的每个字符串，分别和当前数字对应的每个字母拼接起来。

例如：

```python
digits = "23"
```

一开始：

```python
ans = d["2"]
ans = ["a", "b", "c"]
```

然后遍历剩下的数字：

```python
for n in digits[1:]:
```

此时：

```python
n = "3"
d[n] = ["d", "e", "f"]
```

所以：

```python
ans = [a + b for a in ans for b in d[n]]
```

生成过程是：

```text
a = "a": "ad", "ae", "af"
a = "b": "bd", "be", "bf"
a = "c": "cd", "ce", "cf"
```

最后得到：

```python
["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]
```

这其实就是“笛卡尔积拼接”。

## 两种方法的时间复杂度

设 `digits` 的长度是 `N`。

如果每个数字对应的字母数量分别是：

```text
k1, k2, k3, ..., kN
```

那么最终组合数量是：

```text
M = k1 * k2 * k3 * ... * kN
```

因为数字 `7` 和 `9` 对应 4 个字母，其他数字对应 3 个字母，所以最坏情况下：

```text
M = 4^N
```

### 回溯法复杂度

时间复杂度：

```text
O(N * M)
```

最坏情况下可以写成：

```text
O(N * 4^N)
```

原因是最终有 `M` 个组合，每个组合长度是 `N`。在叶子节点执行：

```python
''.join(combination)
```

需要 `O(N)` 时间。

空间复杂度：

```text
O(N + N * M)
```

其中：

```text
O(N)
```

来自递归调用栈和临时路径 `combination`。

```text
O(N * M)
```

来自最终结果 `combinations`。

如果不计算结果数组本身，只看额外辅助空间，则是：

```text
O(N)
```

### 迭代扩展法复杂度

时间复杂度：

```text
O(N * M)
```

最坏情况下可以写成：

```text
O(N * 4^N)
```

原因是最终也要生成 `M` 个长度为 `N` 的字符串，而且 `a + b` 拼接字符串时也需要复制字符串内容。

空间复杂度：

```text
O(N * M)
```

主要来自最终结果 `ans`。

如果只看某一轮迭代时的新旧列表，过程中会有旧的 `ans` 和新的 `ans` 同时存在一小段时间，但数量级仍然是：

```text
O(N * M)
```

## 对比总结

回溯法：

```text
像走迷宫：选一个字母，继续往下一层走；走到底后，退回来换另一个字母。
```

迭代扩展法：

```text
像滚雪球：先有第一位数字的组合，然后每遇到一个新数字，就把已有组合全部扩展一轮。
```

两种方法本质上都必须生成所有答案，所以时间复杂度不会低于答案数量本身。

如果只是为了写起来更短，迭代扩展更直观。

如果是为了训练递归和回溯思想，第一种写法更值得掌握。
