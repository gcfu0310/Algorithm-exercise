# 226. 翻转二叉树

## 题目理解

翻转二叉树，就是对树中的每一个节点交换它的左子树和右子树。

例如：

```text
    4                 4
   / \               / \
  2   7     翻转后   7   2
 / \ / \           / \ / \
1  3 6  9          9  6 3  1
```

无论使用迭代还是递归，核心操作都是：

```python
node.left, node.right = node.right, node.left
```

## 方法一：层序遍历（迭代法）

### 思路

使用队列从根节点开始遍历二叉树：

1. 根节点为空时，直接返回。
2. 将根节点放入队列。
3. 每次从队首取出一个节点。
4. 将它原来的左右孩子加入队列。
5. 交换当前节点的左右孩子。
6. 队列为空时，整棵树翻转完成。

代码中的核心逻辑：

```python
queue = [root]
while queue:
    node = queue.pop(0)
    if node.left is not None:
        queue.append(node.left)
    if node.right is not None:
        queue.append(node.right)
    node.left, node.right = node.right, node.left
```

这里先把左右孩子加入队列，再交换左右孩子，不会影响最终结果，因为加入队列的是节点对象本身，后续仍然会访问到这些节点。

### 复杂度

- 按照层序遍历算法分析，时间复杂度为 `O(n)`，每个节点访问一次。
- 空间复杂度为 `O(w)`，其中 `w` 是二叉树的最大宽度；最坏情况下为 `O(n)`。

### Python 实现注意点

当前代码使用 `list.pop(0)` 删除队首元素。Python 列表删除第一个元素时，后面的元素需要整体前移，因此单次操作不是 `O(1)`，可能使实际时间复杂度退化。

更适合使用 `collections.deque`：

```python
from collections import deque

queue = deque([root])
while queue:
    node = queue.popleft()
```

`popleft()` 的时间复杂度是 `O(1)`，这样才能稳定地实现 `O(n)` 的遍历。

## 方法二：递归法

### 思路

递归处理每一棵子树：

1. 当前节点为空时，结束本次递归。
2. 递归翻转左子树。
3. 递归翻转右子树。
4. 交换当前节点的左右子树。
5. 返回当前节点。

代码中的核心逻辑：

```python
if root is None:
    return
self.invertTree(root.left)
self.invertTree(root.right)
root.left, root.right = root.right, root.left
return root
```

这份代码先处理左右子树，最后处理当前节点，因此可以理解为后序遍历：

```text
左子树 -> 右子树 -> 当前节点
```

递归的关键是：不要只交换根节点，而是让每个节点都执行一次左右孩子交换。

### 复杂度

- 时间复杂度：`O(n)`，每个节点恰好处理一次。
- 空间复杂度：`O(h)`，其中 `h` 是树的高度，空间主要来自递归调用栈。
- 当二叉树退化成链表时，`h = n`，最坏空间复杂度为 `O(n)`。
- 当二叉树较平衡时，树高约为 `log n`，空间复杂度约为 `O(log n)`。

## 两种方法对比

| 方法 | 遍历方式 | 时间复杂度 | 空间复杂度 | 特点 |
| --- | --- | --- | --- | --- |
| 迭代法 | 层序遍历（BFS） | `O(n)` | `O(w)`，最坏 `O(n)` | 使用队列，过程直观 |
| 递归法 | 深度优先遍历（DFS） | `O(n)` | `O(h)`，最坏 `O(n)` | 代码简洁，符合树的递归结构 |

## 易错点与总结

- 空树一定要先判断，否则后续访问左右孩子会报错。
- 两种方法都需要遍历全部节点，区别主要在于一个使用队列，一个使用递归调用栈。
- Python 中实现队列时，优先使用 `deque.popleft()`，不要频繁使用 `list.pop(0)`。
- 当前 `.py` 文件连续定义了两个同名的 `Solution` 类，运行整个文件后，后面的递归版本会覆盖前面的迭代版本。提交或测试时，应只保留一个 `Solution` 类，或者给两个类使用不同名称。
- 本题的本质是：遍历整棵树，并对每个节点交换左右孩子。
