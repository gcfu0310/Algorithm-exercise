# 21. 合并两个有序链表

## 题目目标

给定两个已经升序排列的链表 `list1` 和 `list2`，把它们合并成一个新的升序链表，并返回合并后链表的头节点。

注意：这里的 `list1` 和 `list2` 不是 Python 的 `list`，而是两个链表的头节点。

```python
list1: Optional[ListNode]
```

意思是：`list1` 要么是一个 `ListNode` 节点，要么是 `None`。

## 链表节点的理解

链表不是靠下标访问的，而是靠每个节点的 `next` 指向下一个节点。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

一个节点主要有两部分：

- `val`：当前节点的值
- `next`：下一个节点

例如：

```text
1 -> 2 -> 4
```

可以理解为：

```text
ListNode(1).next = ListNode(2)
ListNode(2).next = ListNode(4)
ListNode(4).next = None
```

## 解法一：递归

递归版本的核心思想是：

先比较两个链表当前头节点的值，谁更小，谁就作为合并后链表当前这一段的头节点。

然后把它的 `next` 指向“剩余部分合并后的结果”。

```python
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        if list1 is None:
            return list2
        if list2 is None:
            return list1

        if list1.val < list2.val:
            list1.next = self.mergeTwoLists(list1.next, list2)
            return list1
        else:
            list2.next = self.mergeTwoLists(list1, list2.next)
            return list2
```

### 递归为什么能成立

假设：

```text
list1 = 1 -> 2 -> 4
list2 = 1 -> 3 -> 4
```

第一次比较两个头节点：

```text
list1.val = 1
list2.val = 1
```

如果走 `else`，说明选择 `list2` 当前节点作为结果链表的头。

接着：

```python
list2.next = self.mergeTwoLists(list1, list2.next)
```

这句话的意思是：

```text
当前选中了 list2 这个节点；
它后面应该接什么？
应该接 list1 和 list2.next 合并后的链表。
```

递归不是单纯“从后往前想”。更准确地说，它是：

1. 先处理当前这一步：选出较小的头节点
2. 把剩下的同类问题交给同一个函数
3. 函数返回后，把当前节点的 `next` 接上

所以它看起来像是“回来时才连起来”，但每一层其实都先决定了当前节点是谁。

## 解法二：迭代

迭代版本更直观，适合第一次理解链表合并。

核心思想：

创建一个虚拟头节点 `prehead`，再用 `prev` 指针一直指向新链表的最后一个节点。

```python
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        prehead = ListNode(-1)
        prev = prehead

        while list1 and list2:
            if list1.val < list2.val:
                prev.next = list1
                list1 = list1.next
            else:
                prev.next = list2
                list2 = list2.next

            prev = prev.next

        prev.next = list1 if list1 is not None else list2
        return prehead.next
```

### 为什么需要 `prehead`

`prehead` 是一个虚拟头节点，不属于最终答案。

它的作用是统一处理“第一个节点怎么接”的问题。

如果没有 `prehead`，我们需要额外判断：

```text
当前是不是第一次接节点？
如果是，应该初始化结果链表的头节点；
如果不是，才用 prev.next 继续接。
```

有了 `prehead` 之后，所有节点都可以统一接到：

```python
prev.next
```

最后返回：

```python
return prehead.next
```

因为 `prehead` 本身只是辅助节点，真正的答案从它的下一个节点开始。

### 为什么最后可以直接接剩下的链表

循环条件是：

```python
while list1 and list2:
```

循环结束时，说明至少有一个链表已经为空。

而另一个链表本身已经是有序的，所以可以直接接到结果链表后面：

```python
prev.next = list1 if list1 is not None else list2
```

不需要一个节点一个节点继续比较。

## 容易出错的地方

### 1. 先访问 `.val`，再判断是否为空

错误写法：

```python
if list1.val < list2.val or list2 is None:
```

如果 `list2` 已经是 `None`，那么 `list2.val` 会直接报错：

```text
AttributeError: 'NoneType' object has no attribute 'val'
```

正确做法是先判断空链表：

```python
if list1 is None:
    return list2
if list2 is None:
    return list1
```

### 2. 以为 `list1` 是 Python 列表

这里的 `list1` 只是变量名，代表“第一个链表的头节点”。

它不是：

```python
[ListNode, ListNode, ListNode]
```

而是：

```text
ListNode -> ListNode -> ListNode -> None
```

## 我对这道题理解的评价

你现在的理解方向是对的，尤其是下面这几点已经抓住了关键：

1. 你意识到递归不容易直接想明白，这很正常。链表递归第一次接触时确实会有“它到底什么时候连起来”的感觉。
2. 你对迭代法的理解比较扎实：初始化一个辅助节点，最后返回 `prehead.next`，这是这道题最重要的技巧之一。
3. 你已经注意到 `list1`、`list2` 本质上是已经串好的链表，不是普通数组。这是理解链表题的入口。

还需要再补强的地方：

1. `list1` 和 `list2` 是“当前还没有合并的链表头节点”，它们会随着算法推进不断向后移动。
2. `prev` 是“结果链表当前最后一个节点”，它负责把新选出来的节点接到答案后面。
3. 递归里返回的不是一个值那么简单，而是“已经合并好的链表头节点”。

这道题建议优先把迭代法吃透。递归法可以先记住这个模型：

```text
选当前更小的节点；
它的 next 等于剩下两条链表合并后的结果；
返回这个更小的节点。
```

等这个模型顺了，递归就不会显得那么玄学。
