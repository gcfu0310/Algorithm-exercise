# 101. 对称二叉树

## 题目要求

给定一棵二叉树的根节点 `root`，判断这棵树是否关于中心轴对称。

## 核心思路

判断一棵树是否对称，本质上是判断根节点的左右子树是否互为镜像。

假设当前比较的两个节点分别是 `left` 和 `right`，它们互为镜像需要满足：

1. `left` 和 `right` 都为空，此时对称。
2. `left` 和 `right` 只有一个为空，此时不对称。
3. 两个节点都不为空，但节点值不同，此时不对称。
4. 节点值相同时，继续交叉比较：
   - `left.left` 和 `right.right`，即外侧节点；
   - `left.right` 和 `right.left`，即内侧节点。

```text
           root
          /    \
       left    right
       /  \    /   \
      A    B  C     D

需要比较：A 和 D、B 和 C
```

---

## 方法一：递归

### 设计思路

定义辅助函数 `is_mirror(left, right)`，用来判断两个节点及其子树是否互为镜像。

递归过程如下：

1. 判断当前两个节点是否为空。
2. 判断两个节点的值是否相同。
3. 递归比较外侧节点和内侧节点。
4. 两组比较结果都为 `True` 时，当前两棵子树才互为镜像。

### 代码

```python
def isSymmetric(self, root: Optional[TreeNode]) -> bool:
    def is_mirror(left: Optional[TreeNode],
                  right: Optional[TreeNode]) -> bool:
        if left is None and right is None:
            return True

        if left is None or right is None or left.val != right.val:
            return False

        return (is_mirror(left.left, right.right)
                and is_mirror(left.right, right.left))

    return root is None or is_mirror(root.left, root.right)
```

### 复杂度

- 时间复杂度：`O(n)`，最坏情况下每个节点都会被访问一次。
- 空间复杂度：`O(h)`，其中 `h` 是树的高度，空间用于递归调用栈。树退化成链表时为 `O(n)`。

---

## 方法二：迭代

### 设计思路

递归方法由系统调用栈保存待比较的节点。迭代方法则主动使用列表保存待比较的镜像节点对。

初始时把 `(root.left, root.right)` 放入列表。之后依次取出一对节点进行判断，并把下一层的镜像节点成对加入列表：

```python
(left.left, right.right)  # 外侧节点
(left.right, right.left)  # 内侧节点
```

这里没有使用 `deque`，也没有使用 `pop(0)`。使用 `index` 依次读取列表元素，可以避免 `pop(0)` 删除首元素时移动其余元素。

### 代码

```python
def isSymmetricIterative(self, root: Optional[TreeNode]) -> bool:
    if root is None:
        return True

    queue = [(root.left, root.right)]
    index = 0

    while index < len(queue):
        left, right = queue[index]
        index += 1

        if left is None and right is None:
            continue

        if left is None or right is None or left.val != right.val:
            return False

        queue.append((left.left, right.right))
        queue.append((left.right, right.left))

    return True
```

### 复杂度

- 时间复杂度：`O(n)`，每个节点最多被检查一次。
- 空间复杂度：`O(n)`，列表最坏情况下需要保存与节点数量同阶的节点对。

---

## 两种方法的区别

| 方法 | 如何保存待比较节点 | 优点 | 注意点 |
| --- | --- | --- | --- |
| 递归 | 系统调用栈 | 代码简洁，镜像关系表达直观 | 树过深时递归栈可能较大 |
| 迭代 | 普通列表和索引 | 不依赖递归，执行过程容易观察 | 节点必须按镜像位置成对加入列表 |

## 易错点

1. 不能比较 `left.left` 和 `right.left`，因为对称要求比较镜像方向。
2. 必须先判断节点是否为空，再访问节点的 `val`。
3. 两个节点都为空时应继续检查其他节点对，不能直接判定整棵树对称。
4. 迭代时应保存节点对，避免丢失两个节点之间的镜像关系。
5. 空树没有不对称的部分，因此返回 `True`。

## 总结

这道题最关键的是把“判断一棵树是否对称”转换成“判断左右两棵子树是否互为镜像”。无论递归还是迭代，节点的比较顺序始终是：

```text
左子树的左节点  对应  右子树的右节点
左子树的右节点  对应  右子树的左节点
```
