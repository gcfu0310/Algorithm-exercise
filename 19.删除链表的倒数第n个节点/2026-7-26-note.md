学习心得：
1、对链表操作的时候，可以通过建立一个哑节点进行操作，可以避免像删除头节点这种特殊情况的特殊操作
2、构建双指针让他们开始时保持n的距离，当先指针到达链表尾部的时候，后指针就位于倒数第n+1的位置，方便直接操作

## 题目目标

给定一个链表，删除链表的倒数第 `n` 个节点，并返回链表的头节点。

删除单链表中的某个节点时，需要先找到它的前驱节点，再执行：

```python
prev.next = prev.next.next
```

因此，本题真正需要定位的是“倒数第 `n` 个节点的前一个节点”。

## 方法一：计算链表长度

1. 第一次遍历得到链表长度 `length`。
2. 倒数第 `n` 个节点就是正数第 `length - n + 1` 个节点。
3. 找到它的前驱节点，也就是正数第 `length - n` 个节点，然后完成删除。

如果 `length - n == 0`，说明需要删除头节点。没有哑节点时，需要单独处理这种情况。

- 时间复杂度：`O(L)`
- 空间复杂度：`O(1)`

其中，`L` 是链表长度。虽然进行了两次遍历，但总时间仍然是线性级别。

## 方法二：栈

1. 创建哑节点 `dummy`，令 `dummy.next = head`。
2. 从 `dummy` 开始，将所有节点依次压入栈中。
3. 弹出 `n` 个节点后，栈顶就是待删除节点的前驱节点。
4. 修改前驱节点的 `next` 指针，最后返回 `dummy.next`。

- 时间复杂度：`O(L)`
- 空间复杂度：`O(L)`

这个方法容易理解，但需要额外的栈空间。

## 方法三：双指针

1. 创建哑节点 `dummy`。
2. `first` 从 `head` 出发，`second` 从 `dummy` 出发。
3. 先让 `first` 向前移动 `n` 次。
4. 再让两个指针同时向前移动，直到 `first` 变为 `None`。
5. 此时 `second` 正好指向待删除节点的前驱节点，执行删除。

这里需要注意当前代码中两个指针的起点不同：`first` 从 `head` 出发，`second` 从 `dummy` 出发；再让 `first` 先移动 `n` 次后，两个指针之间有 `n` 个节点，按位置计算则相差 `n + 1` 条边。当 `first` 到达链表末尾之后的 `None` 时，`second` 正好位于倒数第 `n + 1` 个节点的位置，也就是待删除节点的前驱位置。

双指针移动过程中的不变量是：`first` 和 `second` 之间始终保持上述间隔。这个间隔不变，所以可以利用 `first` 到达末尾的时机确定 `second` 的位置。另一种常见写法是让两个指针都从 `dummy` 出发，并让快指针先移动 `n + 1` 次，两种写法本质相同。

- 时间复杂度：`O(L)`
- 空间复杂度：`O(1)`

该方法只需要一次遍历，并且不需要额外的线性空间，是三种方法中更优的写法。

## 哑节点的作用

哑节点位于原头节点之前，使每一个可能被删除的节点（包括原头节点）都有前驱节点。这样删除头节点和删除其他节点就可以使用同一条语句处理，最终统一返回 `dummy.next`。

例如，链表为 `[1]` 且 `n = 1` 时：

- `dummy -> 1`
- 删除操作为 `dummy.next = dummy.next.next`
- 最终 `dummy.next` 为 `None`

## 边界情况

- 链表只有一个节点，并且删除该节点。
- `n = 1`，删除尾节点。
- `n` 等于链表长度，删除头节点。
- 待删除节点位于链表中间。

## 三种方法对比

| 方法 | 遍历方式 | 时间复杂度 | 空间复杂度 | 是否需要单独处理头节点 |
| --- | --- | --- | --- | --- |
| 计算长度 | 两次遍历 | `O(L)` | `O(1)` | 不使用哑节点时需要 |
| 栈 | 一次遍历 | `O(L)` | `O(L)` | 不需要 |
| 双指针 | 一次遍历 | `O(L)` | `O(1)` | 不需要 |
