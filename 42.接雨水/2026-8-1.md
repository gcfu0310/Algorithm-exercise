# 42. 接雨水

## 题目目标

给定一个非负整数数组 `height`，每个元素表示宽度为 `1` 的柱子高度，计算下雨后能够接住多少单位的水。

例如：

```text
height = [0, 1, 0, 2]
```

下标 `2` 的柱子高度为 `0`，左边最高柱为 `1`，右边最高柱为 `2`，所以这里可以接：

```text
min(1, 2) - 0 = 1
```

个单位的水。

## 核心公式

对于下标 `i`，它能接多少水取决于：

- 从 `0` 到 `i` 的最高柱子 `max_left[i]`；
- 从 `i` 到 `n - 1` 的最高柱子 `max_right[i]`；
- 当前柱子的高度 `height[i]`。

当前位置的水面高度由左右两侧较矮的挡板决定：

```python
water[i] = min(max_left[i], max_right[i]) - height[i]
```

可以理解为：

```text
当前位置水量 = 较矮的最高挡板 - 当前柱子高度
```

这里的左右最高值都包含当前位置，因此：

```text
max_left[i]  >= height[i]
max_right[i] >= height[i]
```

计算结果不会是负数。

---

## 方法一：动态规划（预处理左右最大值）

### 核心思路

先使用两个数组记录每个位置左侧和右侧的最高柱子，再根据核心公式逐个位置计算水量。

```python
def trap(self, height: List[int]) -> int:
    if not height:
        return 0

    n = len(height)
    max_left = [0] * n
    max_right = [0] * n

    max_left[0] = height[0]
    max_right[n - 1] = height[n - 1]

    for i in range(1, n):
        max_left[i] = max(max_left[i - 1], height[i])
        max_right[n - i - 1] = max(
            max_right[n - i],
            height[n - i - 1]
        )

    total = 0
    for i in range(n):
        total += min(max_left[i], max_right[i]) - height[i]

    return total
```

### `max_left` 的含义

```python
max_left[i]
```

表示：

> 从数组开头到下标 `i`（包含 `i`）的最高柱子。

状态转移为：

```python
max_left[i] = max(max_left[i - 1], height[i])
```

到达位置 `i` 时，左侧最高柱只有两种可能：

1. 前一个位置记录的左侧最高柱；
2. 当前柱子本身。

取两者较大值即可。

### `max_right` 的含义

```python
max_right[i]
```

表示：

> 从下标 `i` 到数组末尾（包含 `i`）的最高柱子。

如果单独从右向左遍历，可以写成：

```python
for i in range(n - 2, -1, -1):
    max_right[i] = max(max_right[i + 1], height[i])
```

你的代码把左右两个预处理过程放进了同一个循环：

```python
for i in range(1, n):
    max_left[i] = max(max_left[i - 1], height[i])
    max_right[n - i - 1] = max(max_right[n - i], height[n - i - 1])
```

当 `i` 从左向右增加时：

```text
max_left 处理下标： 1, 2, 3, ..., n-1
max_right处理下标：n-2, n-3, ..., 0
```

因此一个循环同时完成了左右两个方向的计算。

### 初始化为什么这样写？

```python
max_left[0] = height[0]
max_right[n - 1] = height[n - 1]
```

在最左边的位置，从左侧看只有它自己，所以左侧最高值就是 `height[0]`。

在最右边的位置，从右侧看也只有它自己，所以右侧最高值就是 `height[n - 1]`。

这两个值是后续状态转移的起点。

### 示例推导

假设：

```text
height = [3, 0, 2, 0, 4]
```

从左到右计算：

```text
max_left = [3, 3, 3, 3, 4]
```

从右到左计算：

```text
max_right = [4, 4, 4, 4, 4]
```

逐个位置计算：

| 下标 `i` | `height[i]` | `max_left[i]` | `max_right[i]` | 水量 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 3 | 3 | 4 | 0 |
| 1 | 0 | 3 | 4 | 3 |
| 2 | 2 | 3 | 4 | 1 |
| 3 | 0 | 3 | 4 | 3 |
| 4 | 4 | 4 | 4 | 0 |

总水量为：

```text
0 + 3 + 1 + 3 + 0 = 7
```

### 为什么叫动态规划？

因为当前位置的结果使用了前一个已计算结果：

```python
max_left[i] = max(max_left[i - 1], height[i])
max_right[i] = max(max_right[i + 1], height[i])
```

它具备动态规划的基本结构：

- 明确的状态：`max_left[i]`、`max_right[i]`；
- 状态转移：由相邻状态推出当前状态；
- 初始状态：数组最左端和最右端。

### 复杂度

- 时间复杂度：`O(n)`，预处理和求和都是线性遍历；
- 空间复杂度：`O(n)`，需要两个长度为 `n` 的数组。

## 方法二：双指针

### 核心思路

动态规划保存了每个位置的左右最高值，但计算某个位置时，实际上只需要知道当前已经遍历区域的：

```text
left_max 和 right_max
```

因此可以用两个变量代替两个数组，并从左右两端向中间移动。

```python
def trap(self, height: List[int]) -> int:
    n = len(height)
    left, right = 0, n - 1
    left_max, right_max = 0, 0
    total = 0

    while left <= right:
        if left_max < right_max:
            left_max = max(left_max, height[left])
            total += left_max - height[left]
            left += 1
        else:
            right_max = max(right_max, height[right])
            total += right_max - height[right]
            right -= 1

    return total
```

### 四个重要变量

```python
left
```

表示左边下一个等待计算的位置。

```python
right
```

表示右边下一个等待计算的位置。

```python
left_max
```

表示左边已经扫描过的柱子中的最大高度。

```python
right_max
```

表示右边已经扫描过的柱子中的最大高度。

### 双指针的不变量

每轮循环开始时：

- `left` 左边的位置已经计算完成；
- `right` 右边的位置已经计算完成；
- `[left, right]` 是尚未计算的区间；
- `left_max` 是左侧已扫描区域的最高柱；
- `right_max` 是右侧已扫描区域的最高柱。

每轮只确定左端或右端一个位置的水量，然后将对应指针向中间移动。

### 为什么比较 `left_max` 和 `right_max`？

当前位置能接多少水由左右最高挡板中的较矮者决定：

```python
min(left_max, right_max)
```

当：

```python
left_max < right_max
```

右边已经存在一根比 `left_max` 更高的挡板。因此，对于当前左侧位置来说，限制水面高度的一定是 `left_max`。

无论中间或更右边以后还会遇到多高的柱子，都不会改变当前左侧位置由 `left_max` 限制的事实，所以可以立即计算：

```python
left_max = max(left_max, height[left])
total += left_max - height[left]
left += 1
```

反过来，当：

```python
left_max >= right_max
```

左侧已经有不低于 `right_max` 的挡板，当前右侧位置的水面由 `right_max` 决定，因此可以计算右边：

```python
right_max = max(right_max, height[right])
total += right_max - height[right]
right -= 1
```

核心判断可以总结为：

> 哪一侧的已知最高挡板更矮，就先计算哪一侧，因为较矮的一侧已经确定了该位置的水面上限。

### 为什么先更新最大值再计算水量？

左侧写成：

```python
left_max = max(left_max, height[left])
total += left_max - height[left]
```

这样可以保证：

```text
left_max >= height[left]
```

水量不会为负数。

如果当前柱子高于之前的 `left_max`，它会成为新的左侧最高柱，该位置接水量为 `0`。

右侧同理：

```python
right_max = max(right_max, height[right])
total += right_max - height[right]
```

### 示例推导

仍然使用：

```text
height = [3, 0, 2, 0, 4]
```

初始状态：

```text
left = 0
right = 4
left_max = 0
right_max = 0
total = 0
```

由于两个最大值相等，先处理右侧：

```text
right_max = 4
右侧水量 = 4 - 4 = 0
right = 3
```

随后 `left_max < right_max`，开始处理左侧：

```text
位置 0：left_max = 3，水量 = 3 - 3 = 0
位置 1：水量 = 3 - 0 = 3
位置 2：水量 = 3 - 2 = 1
位置 3：水量 = 3 - 0 = 3
```

最终：

```text
total = 7
```

### `left <= right` 的含义

```python
while left <= right:
```

表示只要还有未处理的位置，就继续循环。

当 `left == right` 时，中间还剩一个位置未计算，所以仍然需要处理。处理后指针交错，循环结束。

也可以设计其他等价的双指针写法，例如使用 `left < right`，但相应的初始化和更新顺序必须保持一致，不能只单独修改循环条件。

### 复杂度

- 时间复杂度：`O(n)`，每个位置只被一个指针处理一次；
- 空间复杂度：`O(1)`，只使用固定数量的变量。

---

## 两种方法的联系

两种方法都基于同一个公式：

```python
min(左侧最高柱, 右侧最高柱) - 当前高度
```

区别在于信息的保存方式。

动态规划提前保存所有位置的信息：

```text
max_left[0 ... n-1]
max_right[0 ... n-1]
```

双指针只保存当前需要的信息：

```text
left_max
right_max
```

因此，可以把双指针理解为动态规划的空间优化。

## 方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
| --- | --- | --- | --- |
| 动态规划 | `O(n)` | `O(n)` | 公式直观，容易理解和验证 |
| 双指针 | `O(n)` | `O(1)` | 不保存完整数组，空间效率更高 |

学习时建议先掌握动态规划方法，因为它直接体现每个位置的接水公式；理解公式后，再思考为什么双指针只需要保留两侧当前的最大值。

## 常见误区与易错点

### 1. 不能只看相邻柱子

一个位置能接多少水，取决于它左右两侧的最高柱子，而不是相邻柱子。

例如：

```text
[3, 0, 1, 0, 4]
```

中间位置的水可能由距离较远的 `3` 和 `4` 围住。

### 2. 使用较矮的最高挡板

水会从较矮的一侧流走，所以公式必须是：

```python
min(max_left[i], max_right[i])
```

不能使用 `max`。

### 3. 减去当前柱子的高度

左右挡板决定的是水面高度，真正的水量还要减去当前位置柱子占据的高度：

```python
water = water_level - height[i]
```

### 4. 空数组

动态规划版本需要先判断：

```python
if not height:
    return 0
```

否则访问：

```python
height[0]
height[n - 1]
```

会发生下标错误。

双指针版本在空数组时：

```text
left = 0
right = -1
```

循环不会执行，会自然返回 `0`。

### 5. 双指针的判断与更新顺序必须配套

双指针解法有多种正确写法，有的比较：

```python
left_max 和 right_max
```

有的比较：

```python
height[left] 和 height[right]
```

不同写法的最大值初始化、循环条件和指针移动顺序可能不同。理解并保持一套完整逻辑，不要从不同模板中各取一部分拼接。

### 6. 同名方法会被覆盖

当前 `Solution` 类中定义了两个同名方法：

```python
def trap(...)
```

Python 会让后面的双指针版本覆盖前面的动态规划版本。程序实际调用时，只会执行最后定义的 `trap`。

如果希望在本地同时测试两种方法，可以临时改名为：

```python
def trap_dp(self, height):
    ...

def trap_two_pointers(self, height):
    ...
```

提交到题目平台时，只保留准备提交的 `trap` 方法即可。

## 总结

这道题首先要掌握每个位置的接水公式：

```text
当前位置水量 = min(左侧最高柱, 右侧最高柱) - 当前柱子高度
```

动态规划的思路是：

> 预先计算每个位置的左右最高柱，再逐个位置套用公式。

双指针的思路是：

> 从两端向中间移动，哪一侧的最高挡板更矮，就先确定哪一侧的水量，只保留当前的 `left_max` 和 `right_max`。

因此，双指针并不是一套完全不同的公式，而是对动态规划方法的空间优化。
