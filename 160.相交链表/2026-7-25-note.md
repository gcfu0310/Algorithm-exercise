# 160. 相交链表

## 题目核心

这道题要找的是两个链表的“相交节点”。这里的相交不是指节点的值相同，而是指两个链表从某个节点开始，共用同一个节点对象。

也就是说，判断标准是：

```python
nodeA == nodeB
```

而不是：

```python
nodeA.val == nodeB.val
```

例如两个链表里都出现了值为 `1` 的节点，但如果它们是两个不同的节点对象，就不算相交。

## 方法一：哈希集合 set

### 思路

先遍历链表 A，把 A 中的每一个节点对象存入集合 `seen`。然后遍历链表 B，如果 B 中某个节点已经出现在 `seen` 中，说明这个节点就是两个链表的第一个相交节点。

注意：集合中存的是节点对象本身，不是节点值。

### 代码

```python
class Solution:
    def getIntersectionNode(
        self,
        headA: ListNode,
        headB: ListNode
    ) -> Optional[ListNode]:
        seen = set()

        while headA is not None:
            seen.add(headA)
            headA = headA.next

        while headB is not None:
            if headB in seen:
                return headB
            headB = headB.next

        return None
```

### 复杂度

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(m)`，因为需要额外存储链表 A 的节点

### 易错点

不要这样写：

```python
seen.add(headA.val)
```

因为值可能重复。题目要找的是同一个节点对象，而不是相同的节点值。

## 方法二：双指针

### 思路

设置两个指针 `pA` 和 `pB`，分别从链表 A 和链表 B 的头节点出发。

- `pA` 走完链表 A 后，切换到链表 B 的头节点
- `pB` 走完链表 B 后，切换到链表 A 的头节点
- 如果两个链表相交，两个指针会在第一个相交节点相遇
- 如果两个链表不相交，两个指针最终都会走到 `None`

这里并不是真的修改链表，把两条链表首尾相连；只是让指针在走到末尾之后，换到另一条链表继续走。

### 代码

```python
class Solution:
    def getIntersectionNode(
        self,
        headA: ListNode,
        headB: ListNode
    ) -> Optional[ListNode]:
        pA = headA
        pB = headB

        while pA != pB:
            pA = pA.next if pA is not None else headB
            pB = pB.next if pB is not None else headA

        return pA
```

### 为什么能相遇

假设：

- 链表 A 独有部分长度为 `a`
- 链表 B 独有部分长度为 `b`
- 公共部分长度为 `c`

那么：

```text
pA 走过的路径：A独有 a + 公共 c + B独有 b
pB 走过的路径：B独有 b + 公共 c + A独有 a
```

如果两个链表相交，两个指针最终都会在走过相同长度后到达第一个公共节点。

如果两个链表不相交，两个指针都会分别走完 A 和 B，最后同时变成 `None`，循环结束并返回 `None`。

### 复杂度

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(1)`

## 我的理解总结

哈希表方法比较直观：先记录一条链表中的所有节点，再检查另一条链表中有没有已经出现过的节点。

双指针方法更巧妙：它通过“走完自己的链表后切换到对方链表”来抵消两条链表的长度差。这样两个指针最终走过的总路程相同，所以如果有相交节点，就会在相交节点相遇；如果没有相交节点，就会同时到达 `None`。
