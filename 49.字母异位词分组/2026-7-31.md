# 49. 字母异位词分组

## 一、字母计数解法

这道题常见的字母计数解法如下：

```python
import collections
from typing import List


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = collections.defaultdict(list)

        for string in strs:
            counts = [0] * 26

            for char in string:
                index = ord(char) - ord('a')
                counts[index] += 1

            groups[tuple(counts)].append(string)

        return list(groups.values())
```

核心思想是：

> 字母异位词中每种字母出现的次数相同，因此可以用 26 个小写字母的出现次数作为分组依据。

例如：

```text
"eat"、"tea"、"ate"
```

三个单词中字母 `a`、`e`、`t` 都分别出现一次，所以它们得到相同的计数结果，应当放进同一组。

## 二、`collections` 是什么？

```python
import collections
```

`collections` 是 Python 标准库中的一个模块，提供了一些比普通 `dict`、`list` 更方便的容器。

常见工具包括：

```python
collections.defaultdict
collections.Counter
collections.deque
```

这道题使用的是：

```python
collections.defaultdict(list)
```

需要注意，模块名称是 `collections`，末尾有 `s`，不是 `collection`。

## 三、`defaultdict` 是什么？

普通字典在访问不存在的键时会报错：

```python
groups = {}
groups["abc"].append("abc")
```

因为 `"abc"` 还不是字典中的键，所以会出现：

```text
KeyError: 'abc'
```

使用普通字典时，需要先判断并创建空列表：

```python
if "abc" not in groups:
    groups["abc"] = []

groups["abc"].append("abc")
```

而：

```python
groups = collections.defaultdict(list)
```

表示：

> 当访问一个不存在的键时，自动调用 `list()`，为这个键创建一个空列表。

所以可以直接写：

```python
groups["abc"].append("abc")
```

第一次访问时，它相当于自动执行：

```python
groups["abc"] = []
groups["abc"].append("abc")
```

这里传入的是：

```python
list
```

而不是：

```python
list()
```

因为 `defaultdict` 需要接收一个可以稍后调用的函数。当遇到新键时，它才会调用：

```python
list()
```

生成空列表 `[]`。

## 四、`ord()` 是什么？

`ord()` 是 Python 的内置函数，不需要导入。

它的功能是：

> 将一个字符转换为对应的 Unicode 编码数字。

例如：

```python
ord('a')  # 97
ord('b')  # 98
ord('c')  # 99
```

小写英文字母的编码是连续的，因此可以通过：

```python
ord(char) - ord('a')
```

把字母映射成从 `0` 开始的数组下标：

```text
'a' → 97  - 97 = 0
'b' → 98  - 97 = 1
'c' → 99  - 97 = 2
...
'z' → 122 - 97 = 25
```

例如：

```python
char = 'c'
index = ord(char) - ord('a')
```

得到：

```python
index = 2
```

所以字母 `c` 对应计数数组中的：

```python
counts[2]
```

## 五、`[0] * 26` 是什么意思？

```python
counts = [0] * 26
```

它会创建一个长度为 26、所有元素都是 `0` 的列表：

```text
[0, 0, 0, 0, ..., 0]
```

26 个位置分别对应 26 个小写英文字母：

```text
下标：0  1  2  3  ... 25
字母：a  b  c  d  ... z
```

遇到一个字母，就让它对应位置的数字加一：

```python
counts[ord(char) - ord('a')] += 1
```

因此，`counts` 记录了一个单词中每种字母出现的次数。

## 六、如何统计一个单词？

假设：

```python
string = "eat"
```

最开始：

```text
counts = [0, 0, 0, ..., 0]
```

处理 `e`：

```python
ord('e') - ord('a') == 4
counts[4] += 1
```

处理 `a`：

```python
ord('a') - ord('a') == 0
counts[0] += 1
```

处理 `t`：

```python
ord('t') - ord('a') == 19
counts[19] += 1
```

最终结果表示：

```text
a 出现 1 次
e 出现 1 次
t 出现 1 次
其他字母出现 0 次
```

单词 `"tea"` 和 `"ate"` 虽然字母顺序不同，但是每种字母的出现次数完全相同，所以会得到相同的 `counts`。

这就是字母异位词可以被分到同一组的原因。

## 七、为什么要使用 `tuple(counts)`？

代码使用：

```python
groups[tuple(counts)].append(string)
```

不能直接写成：

```python
groups[counts].append(string)
```

因为 `counts` 是列表，而列表不能作为字典的键。

例如：

```python
groups[[1, 0, 0]] = "abc"
```

会出现：

```text
TypeError: unhashable type: 'list'
```

列表可以被修改：

```python
counts[0] = 100
```

如果一个字典键在放进字典后还能发生变化，字典就无法稳定地定位它。

`tuple()` 可以把列表转换成元组：

```python
counts = [1, 0, 2]
key = tuple(counts)

print(key)
# (1, 0, 2)
```

元组不能被修改，可以作为字典的键。

因此：

```python
key = tuple(counts)
```

相当于使用“26 个字母分别出现了多少次”作为单词的分类标志。

## 八、`append()` 是什么？

```python
groups[tuple(counts)].append(string)
```

`append()` 是列表的方法，用于把一个元素添加到列表末尾。

例如：

```python
words = []
words.append("eat")
words.append("tea")
```

结果为：

```python
["eat", "tea"]
```

在这道题中，拥有相同计数元组的单词会被添加到同一个列表：

```text
相同计数元组 → ["eat", "tea", "ate"]
```

## 九、字典最终是什么结构？

假设输入为：

```python
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
```

处理完成后，`groups` 的逻辑结构大致为：

```python
{
    "a、e、t 各一次": ["eat", "tea", "ate"],
    "a、n、t 各一次": ["tan", "nat"],
    "a、b、t 各一次": ["bat"]
}
```

真实的键不是上面的文字，而是长度为 26 的元组：

```text
字母计数元组 → 属于这一组的单词列表
```

## 十、`groups.values()` 是什么？

```python
groups.values()
```

它用于取得字典中的所有值。

例如：

```python
groups = {
    "key1": ["eat", "tea", "ate"],
    "key2": ["tan", "nat"],
    "key3": ["bat"]
}
```

它的所有值就是：

```python
[
    ["eat", "tea", "ate"],
    ["tan", "nat"],
    ["bat"]
]
```

`groups.values()` 返回的是一个字典视图对象，而题目要求返回普通列表，因此使用：

```python
return list(groups.values())
```

## 十一、`List[str]` 是什么？

```python
from typing import List
```

这里的 `List` 用于类型注解。

```python
strs: List[str]
```

表示参数 `strs` 应当是一个字符串列表：

```python
["eat", "tea", "bat"]
```

返回类型：

```python
-> List[List[str]]
```

表示函数返回一个二维字符串列表：

```python
[
    ["eat", "tea"],
    ["bat"]
]
```

类型注解主要帮助开发者和编辑器理解代码，一般不会主动限制程序运行时传入的数据。

在较新的 Python 版本中，也可以写成：

```python
def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
```


LeetCode 通常要求把解题方法放在 `Solution` 类中，平台会创建对象并调用方法：

## 十三、完整执行过程

输入：

```python
["eat", "tea", "tan", "ate", "nat", "bat"]
```

处理 `"eat"`：

```text
统计字母次数
→ 得到计数元组 key1
→ groups[key1] = ["eat"]
```

处理 `"tea"`：

```text
得到相同的 key1
→ groups[key1] = ["eat", "tea"]
```

处理 `"tan"`：

```text
得到新的 key2
→ groups[key2] = ["tan"]
```

处理 `"ate"`：

```text
得到 key1
→ groups[key1] = ["eat", "tea", "ate"]
```

后面的单词按照相同过程处理，最后通过：

```python
list(groups.values())
```

返回所有分组。

## 十四、与排序方法的区别

自己的排序方法是：

```python
sort_string = sorted(string)
key = ''.join(sort_string)
```

例如：

```text
"eat" → "aet"
"tea" → "aet"
"ate" → "aet"
```

三个单词排序后的结果相同，所以被放进同一组。

字母计数方法使用：

```python
counts[ord(char) - ord('a')] += 1
key = tuple(counts)
```

两种方法使用了不同的分类标志：

```text
排序方法：排序后的字符串
计数方法：每种字母的出现次数
```

假设：

- 一共有 `n` 个字符串；
- 每个字符串的平均长度为 `m`。

两种方法的复杂度为：

| 方法 | 单个字符串 | 总时间复杂度 | 主要分组键 |
| --- | --- | --- | --- |
| 排序 | `O(m log m)` | `O(nm log m)` | 排序后的字符串 |
| 字母计数 | `O(m)` | `O(nm)` | 长度为 26 的计数元组 |

字母计数方法的 26 位数组写法建立在题目只包含小写英文字母的前提下。如果字符串可能包含大写字母、中文或其他字符，就不能直接使用这个固定的映射方式。

## 十五、需要记住的核心

### `collections.defaultdict(list)`

```text
当新键第一次出现时，自动创建一个空列表。
```

### `ord(char) - ord('a')`

```text
把小写字母映射为 0～25 的数组下标。
```

### `[0] * 26`

```text
创建 26 个字母的计数数组。
```

### `tuple(counts)`

```text
把可变列表转换为不可变元组，使它能够作为字典的键。
```

### `groups[key].append(string)`

```text
把拥有相同分类标志的字符串放进同一个列表。
```

### `list(groups.values())`

```text
取出字典中的全部分组，并转换为题目需要的列表。
```

整道题可以总结为：

> 为每个字符串计算一个能够代表其字母组成的键，再用哈希表把具有相同键的字符串收集到同一个列表中。
