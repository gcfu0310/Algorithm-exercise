# 136. 只出现一次的数字

## 题目要求

给定一个非空整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素都出现两次。找出那个只出现一次的元素。

要求：

- 时间复杂度：`O(n)`
- 额外空间复杂度：`O(1)`

## 核心思路：异或运算

这道题最适合用异或运算 `^`。原因是数组中成对出现的数字会在异或时相互抵消，最后只剩下那个只出现一次的数字。

异或的常用性质：

- `x ^ 0 = x`：任何数和 `0` 异或，结果还是它本身。
- `x ^ x = 0`：任何数和自己异或，结果为 `0`。
- 异或满足交换律和结合律：数字的异或顺序不影响最终结果。

因此：

```text
[4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

## 代码实现

```python
from functools import reduce

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        return reduce(lambda x, y: x ^ y, nums)
```

也可以写成更直观的循环形式：

```python
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ans = 0
        for num in nums:
            ans ^= num
        return ans
```

## `reduce` 的用法

`reduce(function, iterable)` 会把序列中的元素从左到右不断合并。

例如：

```python
reduce(lambda x, y: x ^ y, [4, 1, 2, 1, 2])
```

等价于：

```python
((((4 ^ 1) ^ 2) ^ 1) ^ 2)
```

所以这里 `reduce` 的作用就是把数组中的所有数字依次做异或运算。

## `lambda` 函数

`lambda` 可以用来定义一个简单的匿名函数：

```python
lambda x, y: x ^ y
```

含义是：

- 输入两个变量：`x` 和 `y`
- 返回计算结果：`x ^ y`

它等价于下面的普通函数：

```python
def xor(x, y):
    return x ^ y
```

## 复杂度分析

- 时间复杂度：`O(n)`，需要遍历数组一次。
- 空间复杂度：`O(1)`，只使用常数个额外变量。

## 易错点

- `lambda` 不要写成 `lamda`。
- 使用 `reduce` 前需要导入：`from functools import reduce`。
- 哈希表计数也能做出来，但会使用额外空间，不满足题目要求的 `O(1)` 额外空间。
