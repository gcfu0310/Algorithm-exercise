# 206. 反转链表：递归写法理解

## 递归代码

```python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head == None or head.next == None:
            return head

        newhead = self.reverseList(head.next)
        head.next.next = head
        head.next = None

        return newhead
```

## 递归的核心思想

递归反转链表可以理解成：

> 我先不管当前节点 `head`，先让后面的链表 `head.next` 完成反转。

例如原链表是：

```text
1 -> 2 -> 3 -> 4 -> 5 -> None
```

当递归处理 `reverseList(2)` 时，它会把：

```text
2 -> 3 -> 4 -> 5
```

反转成：

```text
5 -> 4 -> 3 -> 2
```

然后当前层只需要把 `1` 接到 `2` 的后面：

```text
5 -> 4 -> 3 -> 2 -> 1
```

## `newhead` 的作用

递归会一直走到最后一个节点：

```text
reverseList(1)
reverseList(2)
reverseList(3)
reverseList(4)
reverseList(5)
```

当 `head = 5` 时，满足终止条件：

```python
if head == None or head.next == None:
    return head
```

此时返回的 `head` 就是节点 `5`。

节点 `5` 是原链表的尾节点，但它会成为反转后链表的新头节点，所以要用：

```python
newhead = self.reverseList(head.next)
```

把这个新头节点保存下来，并且在每一层递归结束时继续返回它。

因此 `newhead` 始终指向节点 `5`。

## 两句反转指针的含义

假设当前递归层中：

```text
head = 4
head.next = 5
```

执行：

```python
head.next.next = head
```

等价于：

```python
5.next = 4
```

链表局部会变成：

```text
4 <-> 5
```

因为原来还有：

```text
4 -> 5
```

所以还必须执行：

```python
head.next = None
```

断开原来的方向，避免形成环。

最后局部变成：

```text
5 -> 4 -> None
```

## 为什么不能 `return head`

如果最后写成：

```python
return head
```

递归过程中的指针仍然会被反转，但是每一层返回的都是当前层自己的 `head`。

最外层的 `head` 是原来的头节点 `1`。反转结束后，节点 `1` 已经变成尾节点：

```text
5 -> 4 -> 3 -> 2 -> 1 -> None
```

但如果返回的是原来的 `head`，外部拿到的是节点 `1`。

从节点 `1` 往后遍历，只能得到：

```text
1 -> None
```

所以它不是“链表没有翻转”，而是“返回的头节点错了”。

## 出栈过程示意

原链表：

```text
1 -> 2 -> 3 -> 4 -> 5 -> None
```

递归到底：

```text
head = 5，返回 5
```

开始出栈：

```text
head = 4:
5.next = 4
4.next = None
返回 newhead，也就是 5

head = 3:
4.next = 3
3.next = None
返回 newhead，也就是 5

head = 2:
3.next = 2
2.next = None
返回 newhead，也就是 5

head = 1:
2.next = 1
1.next = None
返回 newhead，也就是 5
```

最终返回：

```text
5 -> 4 -> 3 -> 2 -> 1 -> None
```

## 记忆方式

递归反转链表可以记成三步：

1. 先递归反转后面的链表。
2. 把当前节点接到后面链表的尾部。
3. 返回新链表的头节点。

对应代码：

```python
newhead = self.reverseList(head.next)  # 1. 后面已经反转好，newhead 是新头
head.next.next = head                  # 2. 让下一个节点指回当前节点
head.next = None                       # 2. 断开当前节点原来的 next
return newhead                         # 3. 返回真正的新头
```

## 小结

`newhead` 的本质作用是保存递归到底后得到的新头节点。链表的方向是靠指针修改完成的，而最终能不能从正确位置遍历整个链表，取决于是否返回了这个新头节点。
